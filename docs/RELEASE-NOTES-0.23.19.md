# Dynote v0.23.19 · 개인·팀 노트 연결 화면

**설정 → 보관함**에는 **개인 노트**와 **팀 노트**가 한 줄씩 표시됩니다. 각 줄을 누르면 해당 노트의 폴더와 연결 상태를 확인할 수 있습니다.

- **이미 쓰던 개인 노트**는 **개인 노트 → 개인 노트 폴더 연결**에서 엽니다. Git 정보가 없는 폴더도 바로 쓸 수 있습니다. 여러 PC에서 이어 쓰려면 **동기화 설정**에서 기기 이름과 저장소 주소를 확인하고 **이 설정으로 동기화**를 누르세요. 처음 올릴 때는 Git 서비스에 빈 저장소를 먼저 만드세요.
- **다른 PC**에서는 **개인 노트 → 기존 Git 저장소에서 가져오기**를 선택하세요. 같은 주소와 브랜치, 이 PC의 이름을 입력하고 빈 폴더를 선택하면 노트가 내려옵니다. 기존 노트와 원격 저장소의 이력이 서로 다르면 Dynote가 원본을 보존하고 빈 폴더로 가져오는 방법을 안내합니다.
- **팀 노트**를 열면 연결된 모델 목록이 보입니다. 모델 이름을 누르면 해당 저장소의 Git 설정이 열립니다. 첫 모델은 바로 등록할 수 있고, 이후에는 **모델 추가**를 사용하세요.
- Windows x64에서는 **설정 → 업데이트 → 시험 버전도 확인 → 지금 업데이트 확인**으로 받을 수 있습니다. 회사 내부 배포처를 사용하는 경우 배포 담당자가 이번 버전의 설치 파일과 `latest.json`을 사내에 게시한 뒤 업데이트할 수 있습니다. Apple Silicon Mac용 DMG와 ZIP도 제공합니다. Mac 앱은 ad-hoc 서명을 사용하며 Apple 공증은 받지 않았습니다.
