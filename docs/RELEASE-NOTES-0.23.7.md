# Dynote v0.23.7 — Windows 설치 프로그램

- Windows x64용 설치 프로그램을 추가했습니다. Setup은 관리자 권한을 요청하지 않고 `%LOCALAPPDATA%\Programs\Dynote`에 설치하며 시작 메뉴에 Dynote를 추가합니다.
- 기존 ZIP에서 옮겨 올 때는 Dynote를 종료한 뒤 Setup을 실행하세요. 같은 Windows 계정의 보관함과 설정을 이어서 사용할 수 있습니다. 앱을 제거해도 노트와 설정은 보관됩니다.
- 설치형의 앱 내 업데이트는 새 Setup을 다운로드합니다. ZIP으로 실행 중이면 ZIP을 다운로드합니다. 업데이트를 적용하려면 Dynote를 종료하고 받은 파일을 직접 실행하거나 압축을 풀어 주세요.
- 문서 탭을 우클릭하면 탭 닫기 옵션을 사용할 수 있습니다. 패널 너비를 조절할 수 있는 범위도 넓혔습니다.

## 설치 파일

- Windows x64는 `Dynote-0.23.7-windows-x64-Setup.exe`로 설치하거나, ZIP을 모두 풀고 `Dynote-win32-x64/Dynote.exe`를 실행하세요. Setup에는 코드 서명이 없습니다.
- Apple Silicon Mac은 DMG에서 Dynote를 응용 프로그램 폴더로 끌어 놓으세요. ZIP도 제공합니다. Apple 배포 공증은 없습니다.
- 플랫폼별 SHA-256 검증 파일을 제공합니다. 앱에서 이 버전을 받으려면 **설정 → 업데이트 → 시험 버전 포함**을 켜세요.
