# Dynote v0.17.0 — 개인·팀 함께 보기와 저널 개선

- **개인·팀 함께 보기**로 두 보관함을 같은 파일 목록에서 열고 검색할 수 있습니다. 문서를 편집 영역 가장자리로 끌어 최대 3개까지 나란히 열고, 경계선을 끌어 너비를 조절할 수 있습니다.
- 두 보관함에 경로와 이름이 같은 문서가 있어도 각각의 보관함에 저장합니다. 개인 공간에서 Copilot 대화를 자동기록하는 동안 팀 문서를 계속 편집할 수 있습니다.
- 저널을 열면 오늘 기록을 **Live Preview**에서 바로 입력할 수 있습니다. 오늘 파일이 없으면 첫 입력을 저장할 때 만듭니다. 지난 기록은 날짜를 눌러 엽니다.
- 한글 입력 중에도 Bullet Threading 연결선을 유지합니다. 이미지가 로드되거나 링크 텍스트에서 이미지로 돌아올 때 연결선이 아래 불릿 위치에 맞춰집니다.
- **설정 → 글꼴**에서 화면·본문·코드별로 시스템 기본과 설치 글꼴을 하나의 목록에서 선택합니다. 이름 검색과 직접 입력을 지원하며 한 곳에서 글꼴과 크기, 본문 줄 간격을 미리 볼 수 있습니다.

## 설치

- Apple Silicon Mac은 `Dynote-0.17.0-macos-arm64.dmg`를 열고 앱을 Applications로 옮기세요. 기존 Dynote는 먼저 종료합니다. Mac 앱에는 ad-hoc 무결성 서명이 적용되며 Apple 공증은 없습니다.
- Windows x64는 `Dynote-0.17.0-windows-x64.zip` 전체를 풀고 `Dynote-win32-x64/Dynote.exe`를 실행하세요. 같은 폴더에 resources와 DLL을 함께 유지합니다.
- 앱에서 베타를 확인하려면 **설정 → 업데이트 → 시험 버전 포함**을 켜고 업데이트를 확인하세요. 플랫폼별 SHA-256 목록과 패키지 검증 결과를 함께 제공합니다.

개인·팀 함께 보기는 **설정 → 보관함**에서 두 폴더의 용도를 각각 개인 노트와 팀 공유 노트로 지정한 뒤 사용할 수 있습니다. 선택한 글꼴과 기존 보관함은 같은 앱 프로필에서 이어서 사용합니다.

## 검증

Mac arm64와 Windows x64에서 자동 테스트, 패키지 소스 비교, 실제 앱의 개인·팀 분할, 저장 분리, 저널 입력, 이미지·연결선, 글꼴, Git과 Copilot 기록 검사를 통과한 패키지를 게시합니다. 검사는 격리된 보관함과 합성 기록을 사용합니다.
