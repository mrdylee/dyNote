# Dynote v0.12.0 — 문서 비교·저널·AI 제공자

## 달라진 점

- 파일이나 탭을 문서 옆으로 끌어 최대 3개 문서를 나란히 보고 편집합니다.
- 시작 화면에서 날짜별 저널을 볼 수 있습니다. 기본 파일 이름은 `Journal/YYYY-MM-DD.md`이며, 설정에서 마지막 문서 열기로 바꿀 수 있습니다.
- 저널 내용을 읽어 기존 폴더를 제안합니다. 미리보기에서 항목과 경로를 확인하고 확정하면 해당 내용을 분류 문서로 저장합니다. 원본 저널은 유지하며, 같은 내용을 중복 분류하지 않습니다. 현재 제안은 로컬 규칙 기반입니다.
- 업데이트는 기본 주 1회 확인합니다. 설정에서 자동 확인·백그라운드 다운로드를 선택하고, ‘지금 확인’도 사용할 수 있습니다. 다운로드와 체크섬 검증 후 준비 완료를 알립니다. ZIP은 직접 압축을 풀어 교체합니다.
- AI 채팅에서 Copilot·Codex·Claude를 선택합니다. 제공자별 대화와 모델 선택은 분리됩니다.

## AI 연결

| 제공자 | 연결 | 지원 기능 |
|---|---|---|
| Copilot | 기존 GitHub 계정 연결 | Agent, Ask, Edit |
| Codex | 설치된 Codex CLI + ChatGPT 로그인 | Ask, Edit |
| Claude | 설치된 Claude Code CLI + Claude 로그인 | Ask, Edit |

Codex·Claude는 설치된 공식 CLI를 사용합니다. Dynote에서 제공자를 선택하고 계정 메뉴의 연결을 누르면 Dynote 전용 프로필로 로그인합니다. 기존 CLI의 로그인 파일을 복사하지 않습니다. 설치·업데이트 후 Dynote를 다시 실행하세요.

- [Codex 설치 안내](https://developers.openai.com/codex/cli): CLI 0.144.5 이상. 이번 배포 검증 버전은 0.166.0입니다.
- [Claude Code 설치 안내](https://code.claude.com/docs/en/setup): CLI 2.1.118 이상. 이번 배포 검증 버전은 2.1.314입니다.
- Windows에서는 두 CLI를 네이티브 Windows에 설치합니다. WSL에만 설치한 CLI는 Windows 앱에서 찾지 않습니다.
- 사용할 모델을 선택한 뒤 현재 문서·선택 영역·문서 없음과 참고 문서를 지정합니다. Edit 결과는 검토 후 적용해야 저장됩니다. 각 제공자의 계정 이용 권한과 사용량이 적용됩니다.
- Codex·Claude는 텍스트 대화와 검토 후 수정을 지원합니다. 여러 문서를 도구로 작업하는 Agent와 플래너의 이미지 분석은 Copilot을 사용합니다.

## Windows 설치

`Dynote-0.12.0-windows-x64.zip` 전체를 새 폴더에 압축 해제한 뒤 `Dynote-win32-x64/Dynote.exe`를 실행합니다. 기존 앱을 닫은 뒤 실행하고, 노트 보관함은 기존 폴더를 그대로 선택할 수 있습니다. `SHA256SUMS-windows-x64.txt`로 다운로드 무결성을 확인할 수 있습니다.

Windows x64를 먼저 배포합니다. Mac 패키지는 이번 배포에 포함하지 않습니다. 기존과 같이 시험판(prerelease)으로 게시합니다.

## 검증 범위

Windows 배포 절차는 전체 단위 테스트, 공식 CLI 초기화·로컬 응답 서버 연동, 패키징, 실제 `Dynote.exe` 창 생성과 정상 종료, ZIP 읽기·체크섬 검증 후에만 게시합니다. Mac의 실제 Electron 화면에서는 제공자 전환·취소·수정안 승인 후 저장과 저널·문서 비교 흐름을 확인했습니다. 실제 사용자 계정 로그인 완료와 유료 모델 추론, Windows 전체 UI 수동 검증은 별도입니다.
