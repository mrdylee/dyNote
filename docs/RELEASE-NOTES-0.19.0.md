# Dynote v0.19.0 — Mermaid와 일지 편집

- **Mermaid** 다이어그램을 Live Preview와 저널 피드에서 볼 수 있습니다. Live Preview에서 도표를 클릭하면 원문을 편집할 수 있고, 커서를 블록 밖으로 옮기면 수정한 내용이 표시됩니다.
- **포스트잇** 첫 줄을 창 상단에서 제목으로 편집할 수 있습니다. 제목은 기존 Markdown 파일에 저장되며, 저장 문제가 있을 때 상태를 표시합니다. 상대 경로 링크와 위키 링크를 열면 메인 창에 해당 문서가 표시됩니다.
- 앱을 켤 때와 날짜가 바뀔 때 **오늘 저널**을 자동으로 만듭니다. 개인·팀 보관함이 연결되어 있으면 개인 보관함을 사용합니다. Copilot 대화 가져오기도 개인 보관함에 저장합니다. 새 폴더에 만들어진 일지도 Git 변경 관리에서 파일 단위로 스테이징할 수 있습니다.
- 파일 목록에서 문서를 폴더로 끌면 **이동**합니다. Ctrl을 누르고 끌면 복사하며, 다른 보관함으로 끌 때는 확인 후 복사합니다. 이름이 겹치거나 복사 후 링크 대상이 달라지는 경우 안내합니다.
- 편집기의 우클릭 메뉴에서 **불릿과 일반 문단**을 서로 변환할 수 있습니다.

## 설치와 업데이트

- Apple Silicon Mac에서는 `Dynote-0.19.0-macos-arm64.dmg`를 열고 앱을 Applications로 옮기세요. Mac 앱에는 ad-hoc 무결성 서명이 적용되어 있으며 Apple 공증은 없습니다.
- Windows x64에서는 `Dynote-0.19.0-windows-x64.zip`을 통째로 푼 뒤 `Dynote-win32-x64/Dynote.exe`를 실행하세요.
- 기존 앱에서는 **설정 → 업데이트 → 시험 버전 포함**을 켜고 업데이트를 확인하세요. 플랫폼별 SHA-256 파일을 함께 제공합니다.
