# Dynote v0.23.22-beta.2 · Windows x64 시험판

개인 노트를 GitHub에 연결할 때 브라우저에서 로그인하고 목록에서 저장소를 선택할 수 있습니다. 새 연결에는 GitHub가 알려준 기본 브랜치를 사용합니다.

1. Windows 설치 파일을 실행하거나 포터블 ZIP을 풀고 `Dynote.exe`를 엽니다.
2. 개인 노트 폴더 이름을 우클릭해 **동기화 설정**을 엽니다. 새 일반 폴더에서는 **GitHub 로그인**이 표시됩니다.
3. 앱에 표시된 일회용 코드를 열린 GitHub 페이지에 입력하고 **Dynote Note Sync**를 승인합니다.
4. 첫 연결에서는 **GitHub에서 저장소 허용**을 눌러 동기화할 저장소를 지정합니다. 앱으로 돌아와 **노트 저장소 → 선택한 저장소 연결**을 누릅니다.
5. **동기화됨**이 표시되면 전송이 끝난 것입니다. 다른 PC에서도 같은 저장소를 선택하면 노트를 받을 수 있습니다.

로그인 정보는 Windows 사용자 계정으로 암호화해 저장합니다. 기존에 연결한 폴더는 저장해 둔 인증과 브랜치로 계속 동기화합니다. 직접 발급한 토큰을 쓰려면 **주소와 토큰으로 직접 연결**을 펼치세요.
