# Dynote v0.23.18 · 사내 배포처에서 Windows 업데이트

외부 GitHub에 접속할 수 없는 Windows x64 Cloud PC에서도 Dynote 업데이트를 받을 수 있습니다. 이 버전을 처음 설치한 뒤 **설정 → 업데이트 → 업데이트 배포처 → 회사 내부**에서 사내 `latest.json`의 HTTPS 직접 다운로드 주소를 저장하세요. 사내 주소는 배포 시 지정할 수 있도록 비워 두었습니다. 개인 PC의 기본 배포처는 GitHub입니다.

- 배포 담당자는 이 릴리스의 Windows `Setup.exe`를 사내 HTTPS 배포 폴더에 먼저 올리고 같은 폴더에 `latest.json`을 마지막에 게시하세요. 두 파일 모두 Dynote가 로그인 화면이나 리디렉션 없이 직접 내려받을 수 있어야 합니다.
- 회사 내부를 선택한 Dynote는 사내 주소만 확인합니다. 자동 확인은 하루에 한 번 진행하며 **지금 업데이트 확인**을 누르면 바로 확인합니다. Windows 설치형 앱은 설치 파일의 크기와 SHA-256을 검증한 뒤 기존 설정에 따라 설치합니다.
- 이전 버전에서 이 시험판을 GitHub로 받으려면 **설정 → 업데이트 → 시험 버전도 확인 → 지금 업데이트 확인**을 선택하세요. Apple Silicon Mac용 DMG와 ZIP도 제공합니다. Mac 앱은 ad-hoc 서명을 사용하며 Apple 공증은 받지 않았습니다.
