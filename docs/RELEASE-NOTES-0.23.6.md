# Dynote v0.23.6 — 목차 가독성과 Copilot 대화 가져오기

- 오른쪽 목차의 탭, 제목, 현재 위치를 더 또렷하게 표시합니다. 긴 한글 제목은 어절 단위로 줄바꿈하며, 긴 목차를 스크롤할 때 상단 탭과 제목이 그대로 표시됩니다.
- Copilot 기록 폴더를 선택하면 해당 폴더에 있는 완료된 대화를 개인 노트로 가져옵니다. 연결된 폴더는 **전체 대화 가져오기**로 다시 확인할 수 있습니다. 기존에 가져온 대화는 중복 저장하지 않습니다.
- 로컬 및 WSL의 VS Code Agent Host 대화 기록을 지원합니다. 개인 노트에 미확정 AI 변경이 있으면 설정에서 해당 노트를 열어 검토할 수 있습니다.
- 파일 트리에서 일간 저널과 날짜별 하위 폴더를 최신 기록부터 표시합니다.

## 설치

- Mac Apple Silicon은 DMG에서 `Dynote.app`을 응용 프로그램 폴더에 복사합니다. ZIP도 제공합니다.
- Windows x64는 ZIP을 모두 푼 뒤 `Dynote-win32-x64/Dynote.exe`를 실행합니다.
- 플랫폼별 SHA-256 검증 파일을 함께 제공합니다.
