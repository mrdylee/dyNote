# Dynote v0.23.9 — Copilot 프로젝트 선택과 초안 후속 편집

- **설정 → Copilot 대화 자동 저장**에서 원하는 프로젝트를 골라 **선택한 프로젝트 가져오기**를 누르면 해당 프로젝트의 과거 대화까지 개인 노트에 저장합니다. **대화 자동 저장**을 켜면 선택한 프로젝트의 새 대화도 1시간마다 확인합니다.
- Copilot Agent에게 미확정 초안을 이어서 수정해 달라고 요청할 수 있습니다. 저장 전 새 문서에서도 후속 편집이 가능합니다.
- 문서를 스크롤해도 **변경 유지**, **변경 되돌리기**, **원본·초안 비교** 버튼이 문서 상단에 표시됩니다.

Windows x64는 `Dynote-0.23.9-windows-x64-Setup.exe`로 설치하거나 업데이트할 수 있습니다. 휴대용 ZIP, Apple Silicon Mac용 DMG·ZIP, 플랫폼별 SHA-256 목록도 제공합니다. 앱에서 이 베타를 받으려면 **설정 → 업데이트 → 시험 버전 포함**을 켜세요.
