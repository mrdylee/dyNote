# Dynote v0.22.0 — 공통 UI와 저장 색상·화면 스포이드

- 일반 노트 작업에 맞춰 ESS LINK 3D 보기와 관련 메뉴·탭·모델을 제거했습니다. 기존 문서의 내용과 연결 메타데이터는 유지합니다.
- AI 채팅의 MCP·스킬 수동 설정 패널을 제거했습니다. 기존 AI 제공자와 설정된 도구 연동은 유지합니다.
- **글자 색상**에서 대표색 12개를 선택하고, 직접 고른 색을 저장·삭제할 수 있습니다. 저장한 색은 노트와 보관함 사이에서 공유되며 앱 재실행 후에도 유지됩니다.
- **화면에서 색 가져오기**로 운영체제의 스포이드를 열어 앱 밖 화면의 색을 선택할 수 있습니다. 선택한 색은 **색상 저장**으로 남기거나 **색상 적용**으로 선택한 글에 적용하세요. Esc로 취소할 수 있으며, 지원되지 않는 환경에서는 버튼이 비활성화됩니다.
- Word 미리보기·본문 검색, Copilot 세션별 저널과 시간당 수집 등 v0.21.0의 기능 및 감사한 개발 브랜치의 변경 이력을 포함합니다.

## 검증 범위

- 기본 팔레트, 사용자 색 저장·삭제·재실행 유지와 선택한 글에 적용하는 흐름을 검증했습니다.
- macOS에서는 사용자가 Chrome 배경을 선택해 실제 화면 색을 가져와 저장하고, 앱 재실행 후 유지되는 것을 확인했습니다. 바탕화면과 Windows의 실제 화면 픽셀 선택은 별도 수동 검증이 남아 있습니다.
- Windows·macOS 배포 파일은 단위 테스트, 패키지 내용·네이티브 실행 시나리오와 체크섬 검증 후 게시합니다.

## 설치와 업데이트

- Windows x64: ZIP 전체를 풀고 **Dynote-win32-x64/Dynote.exe**를 실행하세요.
- Apple Silicon Mac: DMG 또는 ZIP을 사용하세요. 이번 패키지는 기존과 같은 ad-hoc 서명이며 Apple 배포 공증이 없습니다.
- **설정 → 업데이트 → 시험 버전 포함**에서 업데이트를 확인할 수 있습니다. 플랫폼별 SHA-256 파일을 제공합니다.
