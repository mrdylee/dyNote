# Dynote v0.23.21 · 개인·팀 노트 우클릭 동기화

왼쪽의 **개인 노트** 또는 원하는 **팀 공유 노트**에서 제목·폴더·파일을 우클릭하고 **지금 동기화**를 선택하세요. 해당 보관함의 편집을 저장하고 원격 변경을 받아온 뒤 내 변경을 올립니다. 패널 제목 아래의 결과를 누르면 상세 화면이 열립니다. 팀 노트는 선택한 팀의 저장소와 브랜치를 사용합니다.

- **기존 개인 보관함**은 현재 폴더에서 바로 동기화할 수 있습니다. 새 PC에서는 **설정 → 보관함 → 개인 노트 → 기존 Git 저장소에서 가져오기**에서 기존 저장소와 브랜치를 입력하고 빈 폴더를 선택하세요.
- **Windows 기기 등록**은 등록 정보가 같은 JSON의 줄바꿈·들여쓰기·UTF-8 BOM 차이를 처리합니다. 등록 정보가 실제로 달라진 경우 파일을 보존하고 확인할 항목을 알려 줍니다.
- **파일이 다른 PC에 보이지 않으면** 동기화 상세 화면의 전송 대기와 **이 PC에만 있는 항목**을 확인하세요. 개인 노트는 마지막 원격 확인과 업로드 시각을 따로 표시합니다. 공유 폴더에서 수신 중 파일 교체가 실패해 원래 경로를 사용할 수 없으면 **복구 사본 위치 열기**로 이전 파일을 찾을 수 있습니다.
- **팀에서 같은 노트를 동시에 편집하면** Git이 합칠 수 있는 변경은 함께 반영합니다. 충돌이 생기면 양쪽 커밋을 보존하고 패널에 안내합니다.

Windows x64 설치형은 **설정 → 업데이트 → 시험 버전도 확인 → 지금 업데이트 확인**에서 받을 수 있습니다. 사내 배포처를 사용하는 PC는 관리자가 v0.23.21 설치 파일과 `latest.json`을 게시하면 업데이트할 수 있습니다. Apple Silicon Mac에서는 DMG를 열고 Dynote를 응용 프로그램 폴더에 복사하세요.
