# Dynote v0.7.0 — 네이티브 노트 작업 기능

설치된 Obsidian과 활성 플러그인 11개의 프로그램 분석 및 격리된 원본 실행 관찰을 바탕으로, 주요 기능을 Dynote에 직접 구현했습니다. 원본 플러그인 파일이나 API를 실행하는 호환 런타임은 아닙니다.

- 최근 파일·북마크, 명령 팔레트(Cmd/Ctrl+P), 문서 이동(Cmd/Ctrl+K).
- 달력, 일간·주간·월간·분기·연간 노트, 주기별 폴더·파일명·템플릿·주 기준, 시간 기록·평가·과거 같은 날의 일지.
- 목록 하위 트리 이동·들여쓰기·접기·실행 취소, Mermaid 도표 20종 작성 도구.
- 기본/rich 마인드맵 편집·접기·실행 취소·rich 위치 저장과 별도 파일 형식 변환.
- PDF 선택 영역·페이지·주석 링크와 백링크, 강조 추가·메모·색상 변경·주석 삭제. 명시적인 미리보기/저장과 원본 복구 사본을 제공합니다.
- Git 변경·스테이지·차이·커밋·fetch·안전한 빠른 pull·로컬 브랜치, 앱 릴리스 확인·변경사항·베타/무시 설정.
- 문서 선택 영역·제목 단위 추출, 문서 병합·링크 갱신·복구, 읽기 전용 링크 미리보기, 단어 수, 음성 녹음·재생과 격리된 웹 읽기 창.
- 달력 요일/빈 칸과 주간 노트 계산이 선택한 주 기준을 함께 따릅니다. 기존 그래프 드래그 수정도 포함합니다.

문서/PDF 변경은 외부 파일 수정 여부를 검사합니다. PDF 편집은 기존 25MB 제한을 유지하며 암호화·서명 필드가 있는 문서를 거부합니다. 중요한 원본은 별도로 백업하고 먼저 예제 보관함에서 확인하세요.

## 검증과 남은 범위

자동 테스트 210개 통과, 프로덕션 빌드 및 실제 macOS 앱의 11종 기능 시나리오를 검증했습니다. 배포 파일별 점검 결과는 저장소의 검증 기록을 참고하세요. 실제 마이크 대신 합성 오디오 장치로 녹음 흐름을 시험했습니다.

전체 플러그인 기능과 동일하지 않습니다. 고급 마인드맵 내보내기·관계 편집, PDF 페이지/목차/라벨 편집, Diarium 가져오기·날짜 일괄 변환, Git 충돌 해결 등이 남아 있습니다. Obsidian Sync 서비스 호환은 제공하지 않습니다. 상세 범위: docs/verification/native-plugin-support.md.

Mac Apple Silicon과 Windows x64 실행 폴더를 제공합니다. Windows 실제 실행·최초 문서 표시 지연은 미검증이며 이번 릴리스가 기존 Windows 시작 지연을 해결한다고 주장하지 않습니다. 배포 서명·macOS 공증·자동 설치 기능은 없습니다. 일부 큰 번들 경고는 남아 있습니다.

Windows에서는 ZIP 전체를 풀고 `Dynote-win32-x64/Dynote.exe`를 실행하세요. EXE만 따로 옮기면 실행할 수 없습니다.
