# Dynote v0.6.1 — 그래프 품질 회귀 수정

v0.6.0의 오른쪽 그래프 설정을 유지하면서 이전 버전보다 문서 이름이 늦게 나타나던 문제를 수정했습니다.

- 기본 텍스트 밝기와 표시 시점을 v0.5.0과 동일하게 복구했습니다. 텍스트 표시 시작점을 높이면 더 확대해야 이름이 나타납니다.
- 화살표를 끄면 화살표의 도형·GPU 버퍼·좌표 계산을 제거합니다. 켜고 끌 때 노드 배치와 카메라는 유지됩니다.
- 이전 이름 표시량 설정을 옮길 때도 표시 밝기를 유지합니다(검증 범위: 0.5~3).

검증: 153개 자동 테스트 통과. 실제 macOS Electron에서 화살표 표시/해제, 재생 종료 후 유휴 상태, 색상 그룹, 슬라이더, 설정 복원을 확인했습니다. 동일한 1만 문서·2만 연결로 v0.5.0, v0.6.0, 수정 코드를 비교해 최종 노드 좌표가 정확히 일치했습니다. 렌더 콜백 p95는 각각 3.0/3.0/2.9ms였습니다(동일 Mac의 단일 실행, GPU 완료 시간 제외). Obsidian과 동등한 성능을 입증한 결과는 아닙니다.

Mac Apple Silicon과 Windows x64 ZIP을 제공합니다. Windows 실기기 실행은 미검증이며 코드 서명·macOS 공증은 제공하지 않습니다. ZIP을 완전히 푼 뒤 실행하세요.
