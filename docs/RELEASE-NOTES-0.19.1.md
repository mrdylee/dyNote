# Dynote v0.19.1 — Copilot 저널 기간 가져오기

- 저널 자동기록 설정에서 프로젝트와 시작일·종료일을 선택해 이전 Copilot 대화를 가져올 수 있습니다. 각 날짜의 개인 저널에 대화 문서 링크를 추가합니다.
- Windows VS Code에서 열린 WSL 폴더를 프로젝트 목록에 표시합니다. Agent Host 대화는 **WSL 기록 폴더 선택**에서 배포판의 **~/.copilot/session-state**를 연결하면 읽습니다. 연결한 배포판과 선택한 프로젝트의 작업 경로가 일치하는 VS Code 대화를 가져옵니다.
- 새로 가져올 대화가 없을 때 결과를 표시합니다. 자동 스캔 중에도 수동 가져오기 결과를 확인할 수 있습니다.

## 설치와 업데이트

- Windows x64에서는 ZIP을 풀고 **Dynote-win32-x64/Dynote.exe**를 실행하세요.
- Apple Silicon Mac에서는 DMG를 열어 앱을 Applications에 복사하세요. Mac 패키지는 ad-hoc 무결성 서명으로 배포됩니다. Apple 공증 상태는 미공증입니다.
- 앱의 **설정 → 업데이트 → 시험 버전 포함**에서 업데이트를 확인하세요. 플랫폼별 SHA-256 파일을 제공합니다.
