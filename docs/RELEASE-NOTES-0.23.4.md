# Dynote v0.23.4 — Copilot 대화를 정보 문서로

- 개인 노트의 Copilot 세션 문서 상단에서 **문서로 만들기**를 누르면 현재 대화로 정보 문서 초안을 만들 수 있습니다. 초안을 직접 수정하고 개인 노트에 새 Markdown 파일로 저장합니다.
- 정리본에 원본 대화 링크를 넣습니다. 원본의 저장 경로, 저널 링크 및 세션별 재가져오기를 유지합니다.
- **설정 → 문서 프롬프트**에서 기본 프롬프트를 편집하거나 복원할 수 있습니다. 사용자 프롬프트를 추가·수정하고 초안을 만들 때 선택할 수 있습니다.
- 초안을 만들려면 연결된 AI 제공자와 모델이 필요합니다. 긴 대화는 기존 AI 요청 한도에 맞춰 약 192 KiB까지 보냅니다.

## 설치

- Apple Silicon Mac은 DMG 또는 ZIP을 사용합니다. 앱 무결성 서명을 적용합니다. Apple 배포 공증은 없습니다.
- Windows x64는 ZIP 전체를 풀고 `Dynote-win32-x64/Dynote.exe`를 실행합니다.
- 앱의 설정 → 업데이트 → 시험 버전 포함에서도 받을 수 있습니다.
