# Dynote v0.23.3 — Copilot 세션 제목 표시

- 왼쪽 `Copilot Note`에서 프로젝트 아래 파일을 대화 제목으로 표시합니다. 가져오기 기록이 있는 세션은 마지막 대화가 최신인 순서로 정렬합니다.
- 이전 `AI Conversations` 폴더도 같은 방식으로 표시합니다. 복원한 세션 파일에 저장된 기록이 없으면 문서의 첫 제목을 사용합니다.
- 실제 파일 경로를 유지하므로 기존 저널 링크를 열고 같은 세션에 이어서 가져올 수 있습니다.

## 설치

- Apple Silicon Mac은 DMG 또는 ZIP을 사용합니다. 앱 무결성 서명을 적용합니다. Apple 배포 공증은 없습니다.
- Windows x64는 ZIP 전체를 풀고 `Dynote-win32-x64/Dynote.exe`를 실행합니다.
- 앱의 설정 → 업데이트 → 시험 버전 포함에서도 받을 수 있습니다.
