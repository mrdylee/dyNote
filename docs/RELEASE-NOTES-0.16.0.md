# Dynote v0.16.0 — Copilot 저널 자동기록과 가져오기

- **설정 → 저널 자동기록**에서 개인 노트 공간의 VS Code 프로젝트를 선택합니다. 별도 VS Code 확장이나 MCP 설치 없이 로컬 대화 기록을 읽습니다. 자동 기록은 기본으로 꺼져 있습니다.
- 저널 상단의 **가져오기**는 선택한 프로젝트의 오늘 완료된 질문과 답변을 즉시 반영합니다. **자동 기록**을 켜면 활성화 이후 대화를 앱 실행 중 약 5초 간격으로 확인합니다. 입력과 다른 편집 작업 중에는 반영을 미룹니다.
- 프로젝트·현지 날짜별 대화 문서와 저널 링크를 만들며 새 세션도 같은 프로젝트 설정을 따릅니다. 내부 추론, 도구 출력, 첨부파일과 미완료 응답은 가져오지 않습니다.
- 프로젝트 제목 옆 휴지통은 그 날짜 기록과 링크를 함께 제거합니다. **대화 제목 보기**를 펼치면 대화 하나만 삭제할 수 있습니다. **삭제 되돌리기**로 복원하며 삭제한 항목은 자동·수동 재수집에서 제외합니다.
- 코드 예시에 적힌 관리 링크가 실제 링크 생성을 막거나, 삭제할 실제 링크를 가리던 문제를 리뷰 과정에서 수정했습니다. 사용자 메모와 코드 예시는 유지합니다.

## 사용 범위

개인 공간의 로컬 `workspaceStorage` snapshot JSON·mutation JSONL과 대응 Copilot transcript를 지원합니다. VS Code 원본은 변경하지 않습니다. 원격 WSL·SSH·Cloud 대화와 지원하지 않는 형식은 수집하지 않습니다. 소스 파일당 64MB까지 읽습니다. VS Code 저장 형식이 변경되면 지원을 추가해야 할 수 있습니다.

수집 문서는 해당 개인 보관함의 기존 Git 백업 정책을 따릅니다. 삭제는 Dynote의 기록·링크를 대상으로 하며 VS Code 원본과 과거 Git 커밋을 지우지 않습니다. 수집 문서를 직접 수정하거나 이동했을 때에는 자동 덮어쓰기를 멈추고 오류를 표시합니다. 복구 사본은 보관함 밖의 앱 복구 폴더에 저장합니다.

## 설치

Apple Silicon Mac: `Dynote-0.16.0-macos-arm64.dmg`를 열고 앱을 Applications로 옮기세요. 기존 Dynote를 먼저 종료합니다. Mac 앱은 ad-hoc 무결성 서명이며 Apple Developer ID 배포 서명·공증은 없습니다.

Windows x64: `Dynote-0.16.0-windows-x64.zip` 전체를 풀고 `Dynote-win32-x64/Dynote.exe`를 실행하세요. resources와 DLL도 함께 유지합니다. 노트 보관함과 기존 설정은 유지됩니다.

플랫폼별 SHA256SUMS와 패키지 검증 JSON을 함께 제공합니다. 시험판 업데이트를 받으려면 앱 설정의 베타 포함을 켜세요.

## 검증

Mac arm64·Windows x64 네이티브 CI의 테스트·보안 검사·패키지 원본 비교와 실제 앱 시나리오를 모두 통과한 뒤 공개 베타로 게시합니다. 수집 검증은 합성 VS Code 기록과 임시 보관함으로 가져오기, 새 세션, 입력 보존, 삭제·되돌리기, 재시작 제외, 개인·팀 경계를 다룹니다. 실제 VS Code 새 대화 생성이나 실계정 AI 추론은 검증 범위에 포함하지 않습니다.
