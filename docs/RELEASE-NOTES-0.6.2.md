# Dynote v0.6.2 — 그래프 이름 표시 설정 호환성 수정

- 기존 `labels: 0`을 가져오면 일반 문서 이름을 숨긴 상태로 유지합니다. 선택하거나 마우스로 가리킨 노드의 이름은 이전과 같이 표시합니다.
- 기존 표시량 `0.1`을 포함한 0~3의 모든 0.1 단위 설정을 이전 밝기 그대로 변환합니다.
- 그래프 설정의 **표시 → 문서 이름 표시**에서 이름을 켜고 끌 수 있습니다. 보관함별로 저장되며, 재시작 후에도 유지됩니다.
- 이름 표시를 바꿔도 물리 배치를 다시 계산하지 않습니다.

이미 v0.6.0~v0.6.1에서 변환되어 원래 표시량이 사라진 설정은 자동으로 구분할 수 없습니다. 이 경우 표시 메뉴에서 이름 표시를 다시 꺼 주세요. 기존 새 형식의 임계값 3을 일괄적으로 숨김으로 바꾸지 않습니다.

검증: 155개 자동 테스트, 실제 macOS Electron의 표시 전환·설정 복원·이전 설정 변환·화살표·필터·그룹·애니메이션 검증. Mac Apple Silicon 및 Windows x64 배포 파일을 제공합니다. Windows 실기기 실행은 미검증이며 배포 서명·macOS 공증은 제공하지 않습니다.
