# Dynote v0.23.8 — Word 미리보기 가독성 개선

- 보관함에서 열거나 **파일 열기**로 선택한 Word 문서의 본문·표·인용문에 설정한 본문 글자 크기와 줄 간격을 적용합니다. 글자색도 진하게 조정했습니다.
- **설정 → 글꼴 → 본문 글자 크기**를 키우면 문서 제목과 소제목도 함께 커집니다.

Windows x64는 `Dynote-0.23.8-windows-x64-Setup.exe`를 실행해 설치하거나 기존 설치를 업데이트할 수 있습니다. 휴대용 ZIP, Apple Silicon Mac용 DMG·ZIP, 플랫폼별 SHA-256 목록도 제공합니다. 앱에서 이 베타를 찾으려면 **설정 → 업데이트 → 시험 버전 포함**을 켜세요.
