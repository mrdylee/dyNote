# 글꼴 및 Git 자동 저장

왼쪽 아래 톱니바퀴 **글꼴 및 Git 설정**을 엽니다. 이 기능은 v0.4.0부터 Mac·Windows 배포 ZIP에 포함됩니다.

## 설치 글꼴

1. **설치 글꼴 불러오기**를 누릅니다. 이 PC에 설치된 글꼴이 입력란의 후보로 표시됩니다. 목록 접근이 불가능하면 설치된 글꼴 이름을 직접 입력할 수 있습니다.
2. 화면·본문·코드 글꼴을 각각 고릅니다. 화면은 메뉴와 그래프 라벨, 본문은 읽기·Live Preview·Canvas 텍스트, 코드는 소스 편집과 코드 구간에 적용됩니다.
3. 글자 크기와 본문 줄 간격을 조정합니다. 한글·영문 샘플에 반영되고 재실행 후에도 유지됩니다. 지원하지 않는 문자나 다른 PC에 없는 글꼴은 시스템 글꼴로 표시합니다.

글꼴 파일을 복사하거나 업로드하지 않으며 Markdown 내용도 바뀌지 않습니다. 설정은 해당 PC의 앱 프로필에만 저장됩니다. **글꼴 기본값 복원**으로 되돌릴 수 있습니다.

## Git 연결

Git을 설치하고 해당 저장소에 접근할 수 있는 SSH 키 또는 Git 자격 증명 로그인을 먼저 준비합니다. GitHub 웹 로그인만으로 Git 인증이 완료되는 것은 아닙니다. Dynote에서는 대화형 비밀번호 입력을 띄우지 않습니다.

저장소 주소는 나중에 입력해도 됩니다. 주소를 입력하고 연결하기 전에는 Git 자동 저장이 꺼져 있으며 로컬 파일 저장은 계속 사용할 수 있습니다.

- 새 보관함: 노트 전용 빈 원격 저장소를 만든 뒤 현재 폴더를 열고 저장소 주소·브랜치를 입력합니다. **연결하고 자동 저장 시작**을 누르면 Git 저장소를 초기화하고 첫 커밋·업로드를 실행합니다.
- 기존 원격 저장소: 주소와 기존 브랜치를 입력하고 **기존 저장소 가져오기**를 누릅니다. 비어 있는 새 폴더를 선택하면 복제 후 해당 보관함으로 전환합니다.
- 이미 복제한 폴더: Git 저장소의 루트 폴더를 열고 현재 브랜치와 같은 이름을 입력합니다. 상위 저장소에 속한 하위 폴더나 연결된 worktree는 지원하지 않습니다.

주소는 `https://github.com/사용자/노트저장소.git` 또는 `git@github.com:사용자/노트저장소.git` 형태를 지원합니다. 주소에 토큰·비밀번호를 넣지 마세요. 커밋 이름·이메일을 비우면 기존 Git 설정을 사용합니다. 사용자 Git 설정과 기존 `origin`은 변경하지 않으므로 외부 Git 도구에서 가져올 때 필요한 remote·upstream은 별도로 설정해야 할 수 있습니다.

## 저장 동작

- 로컬 자동 저장은 기존처럼 동작합니다. Git은 디스크에 저장된 내용을 기본 **10분**마다 커밋하고 업로드합니다. **자동 저장 간격 (분)**에 1~1440 사이의 정수를 직접 입력하고 **Git 설정 적용**을 누르면 주기가 바뀝니다. 예를 들어 `17`은 17분입니다. 변경한 값은 재실행 후에도 유지됩니다.
- **지금 Git 저장**은 현재 초안의 로컬 저장부터 마친 뒤 실행합니다. 자동 주기는 앱이 열려 있는 동안만 실행됩니다. 종료 시 마지막 원격 업로드를 기다리거나 강제로 실행하지 않습니다.
- 변경이 없으면 새 커밋을 만들지 않습니다. 원격 업로드 대신 **로컬 커밋만**도 선택할 수 있습니다.
- `.md`, `.canvas`, `.base`, PNG·JPEG·GIF·WebP·PDF의 추가·수정·이동·삭제를 반영합니다. 새 숨김 파일, 미지원 파일, 심볼릭 링크는 자동으로 추가하지 않습니다. `.gitignore`는 새 파일에 적용됩니다. **기존 Git 이력에 포함된 파일은 push할 때 함께 전송되므로 노트 전용 저장소를 사용하세요.**
- 설정은 앱 데이터의 `git-backup.json`에 보관함별로 보관합니다. 저장소 주소·브랜치·작성자·주기·활성 상태·마지막 업로드 시간을 저장하며 인증 비밀은 저장하지 않습니다.
- 자동 커밋은 저장소 hook과 커밋 서명을 실행하지 않습니다. 서명 필수 저장소에서는 **로컬 커밋만** 또는 외부 Git 도구의 수동 작업을 사용하세요.

화면 아래 **로컬 저장 상태**와 **Git 상태**는 별개입니다. `Git 원격 저장 완료`는 해당 실행 시점의 커밋이 업로드되었음을 뜻합니다. 업로드 중 새 편집이 저장되면 다시 대기 상태가 됩니다. **자동 저장 끄기**는 주기를 중단하며, 재실행 후에도 꺼진 상태를 유지합니다.

## 오류와 다른 PC의 변경

인증·네트워크 오류가 나도 로컬 문서와 만들어진 커밋은 남습니다. 다음 주기에 재시도하며 **지금 Git 저장**으로도 다시 시도할 수 있습니다. Git이 없으면 설치 후 앱을 재시작합니다.

원격에 다른 PC의 변경이 있으면 업로드를 멈추고 안내합니다. 자동 pull·rebase·강제 push·충돌 해결은 하지 않습니다. 자동 저장을 끄고 외부 Git 도구에서 이력을 통합한 뒤 Dynote의 **문서 새로고침**을 누르고 다시 연결하세요. 직접 스테이징한 변경이나 진행 중인 merge/rebase가 있으면 해당 Git 작업을 먼저 완료해야 합니다.

이 기능은 저장소로 보내는 자동 백업입니다. 양방향 실시간 동기화는 제공하지 않습니다. 외부 Git 작업과 앱의 자동 작업을 동시에 실행하지 마세요.

## 검증

검증은 실제 사용자 노트와 분리한 임시 보관함·bare Git 저장소에서 수행합니다. HTTPS 테스트 주소를 격리된 Git 설정으로 로컬 bare 저장소에 연결하므로 실제 GitHub 저장소에는 업로드하지 않습니다.

`npm test`, `npm run build`, `scripts/verify-settings-runtime.mjs`, `scripts/verify-live-preview-runtime.mjs`로 확인합니다. 실행 검증 환경은 macOS Apple Silicon / Electron 44.9.0입니다. Windows 실행·설치 글꼴 열거·실제 GitHub 인증은 이번 작업에서 검증하지 않았습니다.

2026-10-19: 테스트 98개와 프로덕션 빌드가 통과했습니다. 개발 실행과 패키징된 Mac 앱에서 설치 글꼴 258개 열거, 실제 숫자 입력, 본문·소스·Live Preview의 글꼴/크기 적용, 재시작 후 설정 유지, 실제 30초 자동 업로드, 오프라인 오류·재시도·연결 해제를 검증했습니다. 기존 Live Preview 회귀 검사도 통과했습니다. [검증 기록](verification/fonts-git-runtime.json)

같은 날 사용자 요청에 따라 기본값을 10분으로 바꾸고 분 단위 직접 입력을 추가했습니다. 테스트 99개와 빌드가 통과했고, 새 Mac 패키지에서 주소 미입력·기본값 10분, 잘못된 간격의 적용 차단, 실제 1분 자동 업로드, 직접 입력한 17분의 재실행 후 유지까지 확인했습니다. [분 단위 설정 검증](verification/git-minute-settings-runtime.json)
