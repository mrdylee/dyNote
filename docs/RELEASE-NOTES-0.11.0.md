# Dynote v0.11.0 — Markdown 서식·패널과 AI 작업 개선

## Markdown 작성

- 편집 도구막대에서 굵게·기울임·취소선·인라인 코드와 글자 색상을 적용하고 기본색으로 복원합니다. 색상은 Markdown 파일에 저장되어 읽기 보기와 Live Preview, 재시작 후에도 유지됩니다.
- 편집 화면에서 글꼴·크기·줄 간격 설정을 바로 열 수 있습니다. 기존 화면·본문·코드 글꼴 설정은 그대로 사용합니다.
- 우클릭 메뉴에 복사·잘라내기·붙여넣기와 편집기 서식·실행 취소를 연결했습니다.
- 좌우 패널 경계를 드래그하거나 키보드로 조절하고, 두 번 클릭해 초기화합니다. 너비는 재시작 후 복원되며 창을 줄여도 본문 공간을 남깁니다.

## 앱 정보와 AI

- 상단 Dynote 옆에서 현재 버전을 확인하고 앱 정보 창을 열 수 있습니다.
- AI 기본 전달 범위는 현재 보고 있는 노트입니다. 다른 노트를 열면 그 노트의 내용이 기본으로 전달됩니다. 선택 영역은 직접 선택한 경우만 사용합니다.
- 전송할 수 없을 때 연결·모델·현재 노트·미확정 변경 등의 구체적인 이유와 조치를 표시합니다. 서버가 Auto 모델을 제공하면 첫 연결에서 선택합니다.
- 미확정 AI 수정안이 있어도 Ask 대화를 할 수 있습니다. Agent/Edit의 파일 변경 보호와 문서 크기·선택 영역 검증은 유지합니다.
- GitHub 연결·재연결은 오른쪽 상단 계정 메뉴에 모았습니다. 연결 확인과 새 대화도 같은 제목 줄에 두어 대화 공간을 넓혔습니다.

## 개발 플래너 캡처

- 원본 이미지를 보존하면서 AI 전송용 이미지를 허용 크기에 맞게 준비하고, 준비·연결·읽기·행별 확인의 진행 상태를 표시합니다.
- 긴 인식 결과는 기존 단위별 검사와 검토 페이지로 처리합니다. 원본 행과 후보의 누락·병합 의심 항목을 확인하고 직접 검토한 뒤 등록합니다.
- 실패하거나 취소해도 초기 인식 결과를 유지합니다. 두 번의 인식은 시간과 사용량을 더 쓰며, 완벽한 자동 인식을 보장하지 않습니다. HEIC는 지원하지 않으므로 PNG/JPEG로 사용하세요.

## 다운로드와 설치

- Apple Silicon Mac: `Dynote-0.11.0-macos-arm64.zip` 전체 압축 해제 후 `Dynote-darwin-arm64/Dynote.app`을 실행합니다.
- Windows x64: `Dynote-0.11.0-windows-x64.zip` 전체 압축 해제 후 `Dynote-win32-x64/Dynote.exe`를 실행합니다. DLL과 resources를 함께 유지하세요.
- 무결성 확인: `SHA256SUMS.txt`.

기존 앱을 종료한 뒤 새 앱을 사용하세요. 노트와 계정 설정은 앱 파일과 별도로 보존됩니다. 이전 임시 폴더가 사라졌다는 오류가 보이면 실제 노트 폴더를 한 번 열어 주세요.

## 배포 범위

기존과 같은 프리릴리스입니다. Mac 앱은 ad-hoc 서명과 엄격한 서명 무결성 검사를 거칩니다. Developer ID 서명·Apple 공증을 제공하지 않아 인터넷에서 내려받은 앱은 Gatekeeper가 차단할 수 있습니다. 보안 설정이나 격리 속성을 바꾸는 스크립트는 포함하지 않습니다.

Windows 패키지는 macOS에서 교차 생성하며 실제 Windows 실행은 검증하지 않았습니다. 실제 계정 응답, 임시 보관함의 결정적 재현, 패키지·공개 다운로드 검증은 각각의 근거로 구분합니다. 이번 변경의 상세 기록은 `docs/verification/`에서 확인할 수 있습니다.
