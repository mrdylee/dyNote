# Dynote v0.23.22-beta.7 · Windows x64 시험판

Dynote를 다시 실행하면 이미 열려 있는 메인 창을 표시합니다. 창을 닫아 Sticky Note 아이콘만 트레이에 남아 있거나 메인 창을 최소화한 상태에서도 같은 창으로 돌아갑니다.

Windows 설치형에서는 Sticky Note를 열어 둔 채 **지금 설치하고 다시 시작**을 누를 수 있습니다. 새 버전으로 전환한 뒤에도 편집한 메모는 개인 보관함의 **포스트잇** 폴더에 남습니다.

이전 버전이 이미 여러 개 실행 중이라면 각 트레이 아이콘에서 **Dynote 종료**를 선택한 다음 이 설치 파일을 실행하세요.
