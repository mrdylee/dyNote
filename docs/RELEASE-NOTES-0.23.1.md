# Dynote v0.23.1 — 세션 가져오기와 Mac 이름·업데이트 개선

- Copilot 기록을 프로젝트별로 불러온 뒤 원하는 세션을 선택해 가져옵니다. 선택한 세션의 이전 날짜 대화도 가져오며 기간 선택 입력은 제거했습니다.
- 읽을 수 없는 다른 세션 때문에 정상 세션까지 막히지 않도록 했습니다. 기존 기록 이동 시 선택하지 않은 대화를 추가로 가져오지 않습니다.
- 업데이트 다운로드 폴더를 선택하고, 받은 파일의 경로를 확인하거나 위치를 열 수 있습니다. 네트워크 오류 후에도 이미 검증된 파일의 위치를 확인할 수 있습니다.
- Sticky Note 이름과 메모·불릿·커서 색상을 정리했습니다.
- Mac 개발 실행도 Dynote 이름과 아이콘을 사용합니다. 배포용 Mac 아이콘 파일명은 dynote.icns입니다.
- 기존 브랜치의 개인 저널, 왼쪽 패널 높이 조절, Word·일반 파일 열기, AI 대화와 색상 기능을 포함합니다.

## 설치와 검증

- Apple Silicon Mac: DMG 또는 ZIP. 앱 무결성 서명을 적용하며 Apple 배포 공증은 없습니다.
- Windows x64: ZIP 전체를 풀고 Dynote-win32-x64/Dynote.exe를 실행하세요.
- 설정 → 업데이트 → 시험 버전 포함에서 확인할 수 있습니다.
- macOS와 Windows의 단위 테스트, 패키지 파일 대조 및 네이티브 회귀 검증이 성공한 뒤 두 플랫폼을 함께 게시합니다.
- WSL 기록 처리는 합성 세션으로 검사하며 실제 사용자 Windows/WSL 기록 환경의 검증과 구분합니다.
