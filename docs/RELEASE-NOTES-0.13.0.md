# Dynote v0.13.0 — 저널 블록 작성

## 저널에서 구조를 잡으며 기록

- 새 일간 저널은 첫 블록에 커서를 두고 바로 작성합니다.
- Enter로 새 블록, Tab으로 하위 블록, Shift+Tab으로 상위 단계, Shift+Enter로 같은 블록 안의 줄바꿈을 만듭니다. 하위 블록이 있는 부모에서 Enter를 누르면 기존 자식을 유지하며 새 하위 블록을 만듭니다.
- 들여쓰기 안내선과 하위 블록 접기·펼치기를 제공합니다. 기존 문단형 저널은 그대로 열고 **저널 블록 추가**로 이어 쓸 수 있습니다.
- 이 기능은 설정된 일간 저널에만 적용합니다. 일반 문서와 사용자 저널 템플릿은 바꾸지 않습니다.
- 저장은 일반 Markdown 목록입니다. 기존 AI 수정 기능에 부모·자식 들여쓰기가 그대로 전달되고, 수정안을 검토해 적용합니다. 자동 AI 정리는 실행하지 않으며 모델 이해도 향상을 보장하는 기능은 아닙니다.

## 함께 포함된 수정

- Markdown 열기·생성·저장·합치기·저널 분류의 고정 8MB 제한을 제거했습니다. 기기의 메모리·렌더링 한계와 AI 요청의 별도 크기 한도는 유지됩니다.
- 캡처 인식은 선택한 AI 제공자·계정·모델을 사용합니다. 날짜와 세부사항이 미정인 인식 결과도 AI 초안으로 저장하며, 캡처 전송 크기 초과와 중복 인식 문제를 수정했습니다.
- Copilot·Codex에서 모델이 제공하는 추론 강도, 노트 Agent, 사용자가 연결한 MCP와 스킬을 지원합니다. Claude는 Ask/Edit를 지원합니다. AI는 선택한 제공자 하나만 연결하면 되며 Claude Code 로그인은 필수가 아닙니다.
- 설치 글꼴을 자동으로 불러오고 백업·복원 설정을 정리했습니다.

## 설치와 검증 범위

Apple Silicon Mac은 DMG를 열어 Dynote를 Applications로 옮깁니다. Windows x64는 ZIP 전체를 풀고 `Dynote-win32-x64/Dynote.exe`를 실행합니다. 기존 앱을 정상 종료한 뒤 교체하면 보관함·설정을 유지합니다. 플랫폼별 SHA-256 파일로 다운로드를 확인할 수 있습니다.

배포 워크플로는 Mac과 Windows에서 단위 테스트, 실제 패키지의 저널 입력·AI 수정안 검토·저장·재시작을 검사하며, 두 플랫폼이 모두 통과한 뒤 공개합니다. AI 검사는 합성 문서와 제어된 응답으로 실행하므로 실제 계정 추론 품질이나 외부 MCP 서비스 인증을 검증한 것은 아닙니다.

Mac 앱은 무결성용 ad-hoc 서명을 사용하며 Apple 공증은 없습니다. 인터넷 다운로드의 macOS 실행 허용은 사용자가 시스템 설정에서 직접 결정합니다. 전역 보안 설정은 바꾸지 않습니다.

Logseq의 공식 웹 데모를 REA로 관찰해 작성 동작을 명세하고 독립 구현했습니다. Logseq 코드·데이터베이스를 포함하지 않습니다. [공식 Logseq 튜토리얼](https://github.com/logseq/docs/blob/master/pages/tutorial.md?plain=1)
