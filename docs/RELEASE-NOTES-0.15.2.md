# Dynote v0.15.2 — 저널 설명과 폴더 휴지통 경계 수정

v0.15.1을 다시 리뷰하고 다음 문제를 수정했습니다.

- 보관함 루트나 상위 경로가 외부 폴더 링크로 바뀌었을 때 폴더 휴지통이 그 링크를 따라가지 않도록 했습니다. 삭제 직전 실제 경로가 선택한 보관함의 하위인지 다시 확인합니다. 기본 폴더 보호, 삭제 확인과 복구 가능한 휴지통은 유지합니다.
- 분류 설명 팝업 안으로 마우스를 옮겨도 설명이 유지되고, 마우스·키보드 모두 Esc로 닫을 수 있습니다. 다시 마우스를 올리거나 초점을 두면 설명이 나타납니다.
- 실제 화면에 없는 ‘원문 처리 방법 선택’ 설명을 제거했습니다. 저장할 문서 경로를 확인하고 미리보기 후 복사하는 흐름이며, 원본 저널은 그대로 유지됩니다.
- 플래너·그래프·ESS·첨부 화면에 뒤쪽 저널의 분류 안내가 남지 않도록 표시 범위를 수정했습니다. 저널 작성 중에는 안내 영역 높이를 유지해 본문이 움직이지 않습니다.

## 설치와 검증

Apple Silicon Mac: `Dynote-0.15.2-macos-arm64.dmg`를 열고 기존 앱을 종료한 뒤 Applications로 옮기세요. Mac 앱은 ad-hoc 무결성 서명이며 Apple Developer ID 배포 서명·공증은 없습니다.

Windows x64: `Dynote-0.15.2-windows-x64.zip` 전체를 풀고 `Dynote-win32-x64/Dynote.exe`를 실행하세요. resources와 DLL도 함께 유지합니다. 플랫폼별 SHA256SUMS와 패키지 원본 검증 JSON을 함께 제공합니다.

Mac arm64·Windows x64 네이티브 CI에서 단위 테스트·보안 검사·패키지 원본 비교와 실제 앱 검사를 모두 통과한 뒤 공개 베타로 게시합니다. 리뷰 재현 검사와 기존 Live Preview·우클릭 휴지통·저널·구간 편집·Bullet Threading·저장/재시작·Git·AI 검토 흐름을 포함합니다. AI 검사는 결정적 이벤트이며 실계정 로그인이나 유료 추론을 검증하지 않습니다. 설치 앱과 사용자 노트·계정은 자동으로 바꾸지 않습니다.
