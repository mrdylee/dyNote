# Dynote v0.23.20 · Copilot 중계 Git 설정

**설정 → Copilot 중계 Git**에서 이 PC의 역할과 질문·답변을 교환할 저장소를 확인할 수 있습니다. 관리자가 여러 전용 저장소를 승인했다면 주소를 선택하고 **중계 저장소 적용**을 누르세요. Local PC와 Cloud PC 모두 같은 주소를 선택해야 합니다. 노트 문서의 저장소는 기존 **백업·복원**에서 관리합니다.

Cloud PC의 D-Note에서 승인된 Copilot 계정에 로그인한 뒤 앱을 열어 두세요. Local에서는 Copilot 탭의 **Cloud Ask**에 질문을 입력합니다. 정상 완료된 질문 하나는 전용 저장소에 제출·실행 시작·답변의 세 커밋으로 기록됩니다. 각 질문은 독립적이며 현재 문서와 이전 대화는 자동 전송하지 않습니다.

처음 사용하는 조직은 전용 비공개 저장소, 역할별 서명 키와 관리 설정을 먼저 배포해야 합니다. 기존 단일 저장소 설정은 호환됩니다. 관리자 설정이 없는 PC에서는 기존 Direct Copilot을 사용할 수 있습니다. [관리자 설정과 보존 정책](https://github.com/mrdylee/dyNote/blob/v0.23.20/docs/CLOUD-COPILOT-BRIDGE.md)

Windows x64는 Setup.exe, Apple Silicon Mac은 DMG에서 설치하세요. Mac 앱은 ad-hoc 서명 상태로 배포됩니다.
