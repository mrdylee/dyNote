# Dynote v0.13.1 — 저널 입력 수정

- 자식이 있는 부모 블록의 중간에서 Enter를 눌러도 기존 자식·손자 항목의 소속이 유지됩니다. 나머지 텍스트는 새 하위 블록으로 분리되며 한 번의 되돌리기로 원래 상태를 복원합니다.
- 저널에서 링크 자동완성이 열려 있으면 Enter로 제안을 확정합니다. 미완성 링크 뒤에 새 블록이 생기던 키 처리 충돌을 수정했습니다.

일반 문서, 기존 저널 내용, 사용자 템플릿과 AI 선택은 유지합니다. 기존 [v0.13.0 기능](RELEASE-NOTES-0.13.0.md)을 포함하는 수정본입니다. 별도의 AI 로그인이나 요청을 추가하지 않습니다.

부모·자식 분할과 자동완성 회귀 검사를 Mac·Windows의 실제 패키지 검사에 포함했습니다. 두 플랫폼이 모두 통과한 뒤 새 태그와 배포 파일을 게시하며 기존 v0.13.0 태그·파일은 교체하지 않습니다.

Mac은 DMG에서 Applications로 앱을 옮기고, Windows는 ZIP 전체를 풀어 `Dynote.exe`를 실행하세요. 교체 전 기존 앱을 정상 종료하세요. Mac은 ad-hoc 무결성 서명을 사용하며 Apple 공증은 없습니다. 플랫폼별 SHA-256 파일로 다운로드를 확인할 수 있습니다.
