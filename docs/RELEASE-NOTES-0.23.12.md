# Dynote v0.23.12 · Windows x64

- 보관함, 노트 링크 또는 파일 열기에서 Excel 통합 문서와 PowerPoint 프레젠테이션을 읽을 수 있습니다. Excel은 시트 탭으로, PowerPoint는 슬라이드 이동 버튼으로 탐색합니다.
- **앱에서 수정**을 누르면 Windows에서 해당 형식의 기본 앱으로 지정한 프로그램이 원본을 엽니다. 외부 앱에서 저장하고 Dynote로 돌아오면 보던 위치에서 미리보기가 갱신됩니다.
- 미리보기는 PC에서 로컬로 동작합니다. 파일을 첨부파일로 가져온 경우에는 보관함에 복사한 파일이 편집 대상입니다.

기존 Dynote를 종료하고 `Dynote-0.23.12-windows-x64-Setup.exe`를 실행하세요. 설치형 v0.23.11에서는 **설정 → 업데이트 → 시험 버전도 확인**을 켜면 앱에서 업데이트할 수 있습니다.
