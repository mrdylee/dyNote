# Dynote v0.21.0 — Word 문서 미리보기와 본문 검색

- 보관함에 저장한 `.docx`를 파일 목록에 표시하고, 제목·표·이미지를 읽기 전용으로 미리 봅니다. 파일명과 본문을 전체 검색 및 빠른 문서 이동에서 찾을 수 있습니다.
- **기본 앱에서 열기**로 보관함의 원본 파일을 엽니다. `.docx` 기본 앱을 Microsoft Word로 지정하면 Word에서 수정·저장할 수 있습니다. Dynote로 돌아오면 미리보기와 검색 본문을 갱신하며, 미리보기를 닫아 둔 파일도 검색에 반영합니다.
- Word 원본은 Dynote에서 다시 저장하거나 변환하지 않습니다. Word 잠금 파일은 목록에서 제외하며, 본문 검색과 미리보기는 25MB 이하를 지원합니다. 읽을 수 없는 파일도 파일명으로 찾을 수 있습니다.
- v0.20.0의 Copilot 세션별 저널 기록과 최신 main의 변경을 포함합니다.

## 검증 범위

- 시험용 SWRS 문서의 한국어 본문·표·검색과 외부 변경 반영을 검증했습니다. Windows 11 ARM의 VMware 환경에서도 Dynote 동작을 확인했습니다.
- 실제 Microsoft Word에서의 편집·저장과 Polarion Round-trip 재업로드는 이번 검증에 포함하지 않았습니다. Polarion에는 Word Round-trip으로 내보낸 원본 파일과 해당 내보내기 설정을 사용하세요.

## 설치와 업데이트

- Windows x64에서는 ZIP을 풀고 **Dynote-win32-x64/Dynote.exe**를 실행하세요.
- Apple Silicon Mac 패키지는 ad-hoc 서명이며 Apple 배포 공증이 없습니다.
- **설정 → 업데이트 → 시험 버전 포함**에서 업데이트를 확인하세요. 플랫폼별 SHA-256 파일을 제공합니다.
