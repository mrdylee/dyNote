# Dynote v0.8.0 — 원본 플러그인 실행과 채팅 아이콘 구분

v0.7.0의 네이티브 노트 작업 기능에 원본 Recent Files·Calendar 플러그인을 별도 창에서 실행하는 제한된 호스트를 추가했습니다.

- **설정 → 플러그인 → 플러그인 폴더 가져오기**에서 `manifest.json`, `main.js`, 선택적 `styles.css`가 있는 폴더를 가져온 뒤 켭니다. 프로그램 파일은 변경하지 않으며 기존 개인 `data.json`은 가져오지 않습니다.
- Recent Files **1.7.10**: 문서 열기 순서, 원본 제외 규칙·설정 화면, 기록 저장과 원본 목록에서 Dynote 문서 열기를 연결했습니다.
- Calendar **1.5.10**: 원본 달력 화면에서 기존 날짜 문서를 열거나 원본 확인창을 거쳐 새 Markdown 문서를 만듭니다.
- 플러그인 명령을 Dynote 명령 팔레트에서 실행하며 켜짐 상태·설정·기록을 보관함별로 분리합니다. 끄기·다시 켜기·앱 재시작을 지원합니다.
- AI 채팅 열기 버튼을 **말풍선 아이콘**으로 변경했습니다. Live Preview의 반짝임 아이콘과 구분됩니다.

제3자 플러그인 프로그램은 배포 파일에 포함하지 않습니다. 사용자가 별도로 준비한 플러그인 폴더를 가져오는 방식입니다. Obsidian 프로그램 코드·개인 문서·개인 플러그인 설정·자격 증명도 포함하지 않습니다.

## 검증과 지원 범위

자동 테스트 **218개 통과, 실패·건너뜀 0**, Mac·Windows 패키징과 파일 대조를 완료했습니다. 실제 Mac 배포 앱에서 원본 플러그인 동작 시나리오 11개, 두 아이콘과 버튼 동작, 그래프 드래그 회귀 검사를 통과했습니다. 일부 큰 번들 경고는 남아 있습니다.

검증 대상은 Recent Files 1.7.10과 Calendar 1.5.10의 대표 Markdown 동작입니다. 전체 Obsidian API나 모든 커뮤니티 플러그인의 호환을 제공하지 않습니다. Node·셸·외부 네트워크, 다른 플러그인 연동, 첨부파일 추적·미리보기·드래그·컨텍스트 삭제 등은 지원 또는 검증 범위가 아니며 미지원 모듈/API는 실행 오류로 표시될 수 있습니다. Calendar 2.0 베타는 지원 대상으로 검증하지 않았습니다.

Mac Apple Silicon과 Windows x64 실행 폴더를 제공합니다. Windows는 Mac에서 교차 패키징하며 실제 Windows 실행과 기존 시작 지연은 미검증입니다. 이번 릴리스가 Windows 시작 지연을 해결한다고 주장하지 않습니다. 코드 서명·macOS 공증·자동 설치 기능은 없습니다.

Windows에서는 ZIP 전체를 풀고 `Dynote-win32-x64/Dynote.exe`를 실행하세요. EXE 옆의 `resources`, DLL 등을 함께 유지해야 합니다.
