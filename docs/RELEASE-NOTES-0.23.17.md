# Dynote v0.23.17 · 모델별 팀 저장소 연결

**설정 → 보관함 → 팀 저장소 연결**에서 저장소 주소와 브랜치를 입력하고 모델별 폴더를 선택하세요. **저장소 추가**로 여러 모델을 입력한 뒤 **입력한 저장소 연결**을 누르면 왼쪽 파일 목록에 모델별 폴더 이름이 표시됩니다.

- 빈 폴더에는 지정한 브랜치를 가져옵니다. 기존 작업 폴더는 origin 주소와 현재 브랜치가 일치하면 그대로 연결합니다.
- 일부 연결이 실패하면 성공한 모델은 바로 사용할 수 있습니다. 화면에 남은 항목의 주소·브랜치·폴더를 수정해 다시 시도하세요.
- 각 모델에서 만든 노트는 해당 팀 폴더에 저장됩니다. 개인노트는 기존 보관함과 동기화 설정을 계속 사용합니다.

Windows 설치형은 **설정 → 업데이트 → 시험 버전도 확인 → 지금 업데이트 확인**에서 업데이트할 수 있습니다. Apple Silicon Mac은 DMG를 열고 Dynote를 응용 프로그램 폴더에 복사하세요. Mac 시험판에는 ad-hoc 서명을 적용했으며 Apple 공증은 받지 않았습니다.
