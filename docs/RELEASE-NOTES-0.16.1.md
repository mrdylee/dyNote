# Dynote v0.16.1 — 저널 불릿과 이미지 입력 수정

- 입력 중인 불릿과 마우스를 올린 불릿을 1.2배 강조해 현재 위치를 쉽게 확인합니다.
- 첫 불릿의 시작에서 Backspace를 눌러도 불릿을 유지합니다. 뒤쪽 블록의 시작에서는 이전 블록과 합치고 하위 항목과 실행 취소를 보존합니다.
- 빈 최상위 불릿에서 Enter를 누르면 다음 불릿을 만듭니다. 빈 하위 불릿은 상위 단계로 돌아옵니다.
- 이미지가 포함된 목록에서 Enter마다 빈 줄이 하나 더 생기던 문제를 수정했습니다. 기존 빈 줄을 임의로 제거하지 않고 새 불릿을 한 줄씩 추가합니다.
- 이미지 붙여넣기 후 커서를 다음 불릿에 두고, 이미지 옆 불릿을 첫 행 높이에 정렬합니다. 일반 문서의 첨부 삽입도 커서를 삽입 결과 뒤로 옮깁니다.
- 저널 편집의 기본 모드는 **Live Preview**입니다. 현재 세션에서 문서별로 직접 선택한 보기 모드는 유지합니다.
- 인용문 내부 목록은 일반 Markdown 편집을 유지합니다. 기존 제목·들여쓰기·Bullet Threading·링크 자동완성과 Copilot 저널 자동기록 기능도 포함합니다.

## 설치

Apple Silicon Mac: `Dynote-0.16.1-macos-arm64.dmg`를 열고 앱을 Applications로 옮기세요. 기존 Dynote를 먼저 종료합니다. Mac 앱은 ad-hoc 무결성 서명이며 Apple Developer ID 배포 서명·공증은 없습니다.

Windows x64: `Dynote-0.16.1-windows-x64.zip` 전체를 풀고 `Dynote-win32-x64/Dynote.exe`를 실행하세요. resources와 DLL도 함께 유지합니다. 기존 노트 보관함과 설정은 유지됩니다.

플랫폼별 SHA256SUMS와 패키지 검증 JSON을 함께 제공합니다. 앱에서 시험판 업데이트를 받으려면 베타 포함 설정을 켜세요.

## 검증 범위

공식 Logseq 2.0.2 Mac 데스크톱 앱을 격리 실행하고, REA 배포본 분석과 실제 입력·스타일 관찰을 병행했습니다. 기본 hover의 1.2배 비율을 입력 중인 불릿에도 적용한 것은 사용자 요청을 반영한 동작입니다. 전체 Logseq 기능과의 동일성을 의미하지 않습니다.

Mac arm64·Windows x64 CI의 테스트·보안 검사·패키지 원본 비교와 실제 앱 시나리오를 모두 통과해야 공개 베타를 게시합니다. 새 native 검사는 불릿 강조·Backspace·빈 불릿 Enter·이미지 붙여넣기·한 줄 간격·첫 행 불릿 정렬을 검증합니다. AI 검증은 합성 기록과 결정적 테스트 이벤트를 사용하며 실계정 추론은 포함하지 않습니다.
