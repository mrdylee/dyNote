# Dynote v0.23.0 — 개인 저널과 왼쪽 패널 높이 조절

- 왼쪽에 **저널** 바로가기를 추가했습니다. 명령 팔레트에서 **저널** 또는 **journal**로 검색해 열 수 있습니다.
- 기본 저널, 달력, 오늘·주간·월간·분기·연간 일지 생성은 **개인 노트**를 사용합니다. 팀 문서를 보고 있어도 개인 공간에 저장합니다. 개인 공간이 없으면 **개인 노트 설정**을 안내합니다.
- 개인 노트만 연결한 경우에도 저널 화면의 왼쪽에서 폴더와 파일을 볼 수 있습니다. 달력은 **달력과 일지** 버튼으로 엽니다.
- **문서 공간 → 전체 공간**에서 개인 노트와 팀 노트 사이 경계선을 위아래로 드래그하면 높이가 바뀝니다. 각 영역을 따로 스크롤할 수 있으며 조절한 비율은 저장됩니다. 경계선을 두 번 클릭하면 반반 배치로 돌아갑니다. 키보드 ↑·↓도 지원합니다.
- 개발 플래너는 일정, AI 채팅은 말풍선 아이콘을 사용해 Live Preview와 구분했습니다.
- 기존 파일은 옮기지 않습니다. 기존 저널의 폴더·템플릿 설정과 개인·팀 문서의 저장 공간은 유지합니다.

## 설치와 업데이트

- Windows x64: ZIP 전체를 풀고 **Dynote-win32-x64/Dynote.exe**를 실행하세요.
- Apple Silicon Mac: DMG 또는 ZIP을 사용하세요. 앱 무결성 서명을 적용하며 Apple 배포 공증은 없습니다.
- **설정 → 업데이트 → 시험 버전 포함**에서 업데이트를 확인하세요. 플랫폼별 SHA-256 파일과 패키지 검증 결과를 제공합니다.

## 검증

- Windows와 macOS에서 단위 테스트, 패키지 파일 대조와 실제 실행 검증을 통과한 뒤 두 플랫폼을 함께 게시합니다.
- 저널의 개인 공간 저장·트리 표시, 한영 명령 검색, 경계선 드래그·취소·높이 제한·독립 스크롤·비율 복원·공간 필터와 기존 문서·파일 기능을 확인합니다.
