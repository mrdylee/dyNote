# Dynote v0.23.15 · Windows x64

- **설정 → 보관함 → 개인 노트 Git 설정**에서 개인 저장소 주소를 입력하거나 연결 상태를 확인할 수 있습니다. 개인 노트가 아직 연결되지 않았으면 먼저 폴더를 선택합니다.
- 왼쪽 목록에서 `Copilot Note` 폴더를 삭제했을 때, **설정 → Copilot 대화 자동 저장 → 선택한 프로젝트 가져오기**를 누르면 Dynote에 남아 있는 해당 프로젝트의 대화를 복구합니다. 이전에 가져온 대화는 VS Code 원본 파일이 정리된 경우에도 복구할 수 있습니다.
- 가져오기 설정에 실제 개인 노트 경로를 표시합니다. 원본과 이전 기록이 모두 없으면 확인해야 할 기록 폴더를 안내합니다.

기존 설치형은 **설정 → 업데이트 → 시험 버전도 확인 → 지금 업데이트 확인**에서 업데이트할 수 있습니다.
