# Dynote v0.6.3 — 그래프 점 드래그 동작 수정

- 그래프 점을 잡고 멈춰 있어도 주변 점들이 계속 재배치됩니다.
- 점을 놓을 때 계산을 불필요하게 다시 시작하거나, 잡고 있는 동안 쌓인 속도로 튕기던 문제를 수정했습니다.
- 그래프 계산 준비가 끝나기 전에 드래그를 마쳐도 마지막으로 옮긴 위치를 반영합니다.
- 드래그 취소와 포인터 캡처 해제 후에는 고정을 풀고 정상적으로 계산을 종료합니다.

점을 놓은 뒤에는 기존 중심력·링크 장력에 따라 주변 배치가 자연스럽게 조정됩니다. 점을 영구 고정하거나 앱 재시작 후 좌표를 복원하는 기능은 아닙니다. 이전 이름 표시 설정 수정도 포함합니다.

검증: 159개 자동 테스트, 실제 macOS Electron의 드래그·놓기·취소·배치 종료 및 1,000개 문서 그래프 검증. Mac Apple Silicon 및 Windows x64 배포 파일을 제공합니다. Windows 실기기 실행은 미검증이며 배포 서명·macOS 공증은 제공하지 않습니다.

Windows에서는 ZIP 전체를 풀고 `Dynote-win32-x64` 폴더의 `Dynote.exe`를 실행하세요. EXE만 따로 옮기면 실행할 수 없습니다. 이번 패치는 별도로 보고된 Windows 시작 지연의 해결을 보장하지 않습니다.
