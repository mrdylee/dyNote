# Dynote v0.23.22-beta.10 · Windows x64 시험판

- Copilot 기록을 가져온 뒤 프로젝트나 노트 보관함의 위치가 바뀐 경우에도 기록을 다시 찾을 수 있도록 복구 처리를 개선했습니다. 다시 가져온 뒤에는 가장 최근 작업을 실행 취소할 수 있습니다.
- Copilot Agent 및 Edit에 보내는 내용에서 Markdown 표 구조를 유지합니다.
- 문서 탭이나 보기 모드를 바꿨다가 돌아오면 각 문서 창의 읽기 위치를 복원합니다. 분할 보기에서는 마지막으로 사용한 쪽을 다시 선택합니다.
- beta.9의 PDF 형광펜과 휠 페이지 이동을 포함합니다.

Windows x64에서는 Dynote를 종료한 뒤 `Dynote-0.23.22-beta.10-windows-x64-Setup.exe`를 실행하세요.
