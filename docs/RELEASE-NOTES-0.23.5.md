# Dynote v0.23.5 — 문서 목차와 프로젝트 지침

- 오른쪽 패널에서 **목차**, **Copilot**, **문서 정보**를 선택할 수 있습니다. 마지막으로 선택한 패널을 기억하며 처음에는 목차를 표시합니다.
- 문서 목차에 제목의 계층과 현재 읽는 위치를 표시합니다. 제목을 누르면 편집·Live Preview·분할·읽기 모드를 유지하면서 해당 위치로 이동합니다. 같은 제목이 반복되어도 선택한 위치로 이동합니다.
- 목차와 Copilot을 전환해도 입력 중인 대화 초안이 유지됩니다.
- 앱 시작 단계와 소요 시간을 로컬 진단 로그에 기록합니다. 노트 내용이나 오류 메시지는 기록하지 않습니다.
- 저장소의 Copilot 지침에 설명 중 Mermaid 도표를 채팅 안에 표시하는 규칙을 추가했습니다. 이 지침은 이 저장소를 여는 개발용 Copilot에 적용됩니다.
- 기존 브랜치의 변경과 미커밋 작업을 비교하여 최신 `main`에 포함된 기능을 보존했습니다.

## 설치

- Apple Silicon Mac은 DMG 또는 ZIP을 사용합니다. 앱 무결성 서명을 적용합니다. Apple 배포 공증은 없습니다.
- Windows x64는 ZIP 전체를 풀고 `Dynote-win32-x64/Dynote.exe`를 실행합니다.
- 앱의 설정 → 업데이트 → 시험 버전 포함에서도 받을 수 있습니다.
