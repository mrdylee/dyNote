## 편집할 때 유용한 기능

| 편집 상황 | Notion에서 확인한 동작 | Dynote 적용 |
| --- | --- | --- |
| 문장 중 한 단어나 구문 강조 | 드래그한 텍스트의 편집 메뉴에서 굵게·기울임·취소선·코드·글자색 적용 | 기존 Markdown 서식을 재사용한다. 도구 모음에 현재 적용 대상이 표시되고, 우클릭 서식 메뉴에서도 크기와 글자색을 적용할 수 있다. |
| 한 항목 전체 강조 | 블록 메뉴에서 블록 전체의 색 변경 | 선택이 없으면 커서가 있는 줄의 본문에 적용한다. 제목 기호, 목록 번호, 체크박스는 유지한다. |
| 같은 의미를 같은 색으로 반복 표시 | Cmd/Ctrl + Shift + H로 최근 색 반복 | 앱을 연 동안 마지막으로 적용한 글자색을 같은 단축키로 다른 줄이나 선택 영역에도 적용한다. |
| 글자를 크게 표시 | 제목 블록과 페이지 단위의 작은 글씨 설정 | Dynote에는 단어나 현재 줄을 125% 또는 150%로 확대하는 기능을 추가했다. 기본 크기로 복원하면 색과 굵기는 유지된다. |
| 기존 문단을 제목으로 바꾸기 | 블록 메뉴에서 제목으로 전환하거나 새 줄에 `#`, `##`, `###`와 공백을 입력 | 후속 후보. 기존 문단을 제목으로 바꾸는 메뉴는 단순 확대와 달리 문서 목차에도 반영할 수 있다. |
| 배경 강조·밑줄 | 선택 영역의 배경 강조색과 밑줄 지원 | 후속 후보. 글자색을 바꾸지 않고 검토할 구절을 표시할 때 적합하다. |

Notion이 설명하는 글자색·블록색·반복 단축키와 크기 설정의 범위는 공식 문서에서 확인할 수 있다. [Notion 글꼴·크기·색상](https://www.notion.com/help/customize-and-style-your-content)

## Dynote 사용 방법

1. 노트를 편집 보기나 Live Preview로 열고 단어를 드래그하거나 서식을 적용할 문장에 커서를 둔다. 도구 모음에 **선택 영역** 또는 **현재 줄**이 표시된다.
2. **굵게** 또는 **글자 크기 → 크게 (125%) / 더 크게 (150%)**를 선택한다. 글자색은 팔레트에서 고른 뒤 **색상 적용**을 누른다.
3. 크기만 되돌리려면 **글자 크기 → 기본 크기**, 색만 되돌리려면 **기본색**을 누른다. **글꼴·크기** 버튼은 앱 전체 표시 설정을 연다.
4. 읽기 보기에서는 완성된 서식을 확인할 수 있다. 파일에는 굵기를 위한 Markdown 표식과 크기·색을 위한 제한된 HTML span이 저장된다. 다른 Markdown 뷰어에서 인라인 스타일을 허용하는지에 따라 표시 결과가 달라질 수 있다.
