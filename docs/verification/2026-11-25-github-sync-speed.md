# Git과 GitHub REST의 개인 노트 동기화 속도

실제 GitHub에서 한글 노트 한 개를 보내고 다른 보관함에서 받기까지 기존 Git은 4.78초, REST는 5.29초가 걸렸다. 열 개를 한꺼번에 수정하면 각각 5.00초와 8.76초였다. 변경이 없는지 한 보관함에서 확인할 때는 Git 0.85초, REST 0.35초였다. 각 수치는 6회의 중앙값이다.

## 상황별 측정값

전체 시간은 A의 로컬 저장 시작부터 A와 B에서 차례로 **지금 동기화**가 끝날 때까지다. 변경이 없을 때는 두 보관함의 확인 시간만 들어간다. 각 열의 중앙값을 독립적으로 계산했다. [48회 측정 원자료](2026-11-25-github-sync-speed.csv)

| 변경량 | 방식 | A 로컬 저장 (ms) | A 동기화 (초) | B 동기화 (초) | 전체 중앙값 (초) | 전체 최소~최대 (초) |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 4 KiB 한글 노트 1개 | Git | 1.25 | 2.93 | 1.81 | 4.78 | 4.56~5.03 |
| 4 KiB 한글 노트 1개 | REST | 1.24 | 3.35 | 1.94 | 5.29 | 5.08~5.92 |
| 4 KiB 한글 노트 10개 | Git | 7.45 | 3.00 | 1.97 | 5.00 | 4.73~5.44 |
| 4 KiB 한글 노트 10개 | REST | 8.87 | 3.77 | 4.96 | 8.76 | 8.71~9.09 |
| 1 MiB WAV 첨부 1개 | Git | 9.96 | 3.88 | 2.08 | 5.87 | 5.29~6.82 |
| 1 MiB WAV 첨부 1개 | REST | 8.89 | 5.22 | 2.32 | 7.70 | 6.68~8.19 |
| 변경 없음 | Git | — | 0.85 | 0.86 | 1.71 | 1.64~1.94 |
| 변경 없음 | REST | — | 0.35 | 0.35 | 0.70 | 0.62~0.82 |

10개 수신 시 REST 요청 14건 중 10건은 파일 내용을 각각 읽는 요청이었다. 이 10건에 걸린 시간의 합은 중앙값 3.29초였다. Git은 파일 한 개와 열 개 모두 원격 명령 두 번으로 수신했다. CSV의 `remote_ops`는 Git에서는 네트워크를 사용하는 Git 명령 수, REST에서는 HTTP 요청 수다. Git 내부의 HTTP 왕복은 별도로 세지 않았다.

## 재현 조건과 데이터 확인

- 검증 대상은 Dynote 커밋 `cc8bc9d`의 **여러 PC에서 이어 쓰기**와 **GitHub API로 이어 쓰기**다. Apple Silicon Mac 한 대에서 모드마다 A·B 임시 개인 보관함을 열었다. Node.js v25.9.0, Apple Git 2.54.0, 기존에 인증한 동일 계정과 실제 비공개 GitHub 저장소를 사용했다.
- 같은 시작 커밋에서 두 시험 브랜치를 만들고 4,096바이트 한글 노트 11개로 시작했다. 매 회차에 노트 한 개와 별도 노트 열 개를 편집하고, 압축으로 크기가 줄지 않는 1,048,576바이트 합성 WAV 한 개를 새로 추가했다. 변경 없는 확인도 반복했다. 각 조건에서 두 방식이 먼저 실행된 횟수는 세 번씩이다.
- 텍스트는 앱에서 쓰는 `GitController.saveNote`와 `Vault.save`, 첨부는 `Vault.transferDroppedFile`, 수동 전송은 `GitController.sync`로 실행했다. Git은 네이티브 HTTPS, REST는 Node의 `fetch`를 사용했고 각 보관함의 HTTP 연결 풀을 분리했다. 계정 로그인, 최초 연결, 화면 그리기, 자동 동기화 대기, 측정 후 무결성 검사는 표의 시간에서 제외했다.
- 48회 각각 A·B의 파일 내용과 GitHub의 Git blob 해시를 대조했다. 최종 사용자 파일은 모드마다 17개, 6,336,512바이트였으며 경로·모드·내용 해시가 일치했다. 시험 전후 저장소 기본 브랜치의 커밋도 같았다.
- 두 방식은 약 55~60초마다 자동 확인한다. 기존 Git 방식은 편집을 약 5분 단위로 묶어 자동 전송한다. 다른 PC에 자동으로 보일 때까지의 시간에는 이 대기가 더해질 수 있다. [자동 확인과 수동 동기화](../../electron/git-controller.mjs) · [Git 묶음 전송](../../core/personal-sync.mjs)
