# 문서 생성 탭·드래그 검증

기준: `cb5be7d`, 작업 브랜치 `feat/copilot-document-tabs`, macOS 소스 실행.

## 동작

- Copilot Note 문서 경로 행 오른쪽에 `문서로 만들기`를 배치했다. 새 임시 탭에서 기존 프롬프트·모델 선택 후 `초안 만들기`를 누른다.
- 생성 중에도 노트 탐색·편집이 가능하며, 생성 탭 전체 색상과 회전 아이콘이 작업 상태를 표시한다. 완료 시 다른 문서의 포커스를 빼앗지 않는다.
- 앱 데이터 `tmp/copilot-documents`에 초안 JSON을 저장하고 재시작 시 복원한다. 완료된 탭에서 `어디에 저장할까요?`와 원본 보관함의 폴더·파일명 선택을 표시한다. 이름 충돌 시 내용을 보존하며 저장 성공 후 임시 파일을 정리한다.
- 저장 실패 원인: 기존 `saveCopilotDocument`가 전역 `flush()`를 호출하여 다른 보관함의 Copilot 미확정 변경까지 검사했다. 새 파일 생성에서 이 호출을 제거하고 대상 경로의 미확정 변경과 기존 파일 충돌만 검사한다.
- 개인·팀 보관함 제목/빈 공간과 폴더/파일 우클릭 메뉴에 폴더 추가를 제공한다.
- 탭/트리에서 왼쪽 패널로 드롭하면 기본 이동, Ctrl 복사다. 이동은 출발/도착 경로를 표시하는 `이동할까요?` 확인 후 실행한다.
- 같은 보관함의 Markdown 본문에 탭을 놓으면 링크를 삽입한다. 편집 모드는 드롭 위치, 읽기 모드는 본문 끝에 삽입한다. 원본 탭은 유지하고 미리보기만 420ms 동안 복귀한다. 모션 감소 설정에서는 애니메이션을 생략한다.

## 확인 결과

- `npm test`: 510개 통과, 실패 0.
- `npm run build`: 통과. 기존 번들 크기 안내 외 실패 없음.
- `scripts/verify-document-tabs.mjs`: 제어된 AI IPC 응답과 실제 Electron/파일/편집기로 검증.
  - 생성 도중 다른 노트 탐색, 완료 후 포커스 유지, 임시 파일 보관/복원/정리.
  - 기존 파일 충돌 후 초안 유지, 빈 초안 편집, 다른 보관함의 미확정 변경과 원본 파일 보존.
  - 팀 루트 우클릭 폴더 추가, Ctrl 복사, 이동 취소/확인, 보관함 간 이동.
  - 편집/읽기 모드 링크 삽입 및 클릭 이동, 복귀 애니메이션과 모션 감소 설정.
  - Chromium DragEvent와 `DYNOTE_NATIVE_DRAG=1` 실제 마우스/Control 키 양쪽 확인.
- `scripts/verify-tree-transfers.mjs`: 실제 마우스 드래그, 저장 대기 중 문서 이동, 링크 갱신, Ctrl 복사, 이름 충돌 보호, F2/우클릭 이름 변경 통과.
- 임시 저장과 폴더 생성 테스트는 미구현 상태에서 실패를 확인한 후 통과했다. 보관함 간 이동의 복구본과 별칭 링크 보호도 회귀 검증했다.

## 범위

실제 AI 서비스 호출, Windows 실행, 설치본 교체, 배포는 검증하지 않았다. 내부 링크는 같은 보관함 범위이며 다른 보관함의 탭은 먼저 복사하도록 안내한다. 보관함 간 이동/복사로 연결이 깨질 경우 기존 링크 검증이 작업을 막고 원본을 보존한다.

후속 리뷰와 종료 직전 저장, 자동 업데이트 관련 최신 검증은 [리뷰 기록](2026-11-20-update-install-review.md)을 참고한다.
