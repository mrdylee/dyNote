## 실제 실행 결과

합성 일정 PNG를 앱에 넣어 자동 변환, 실제 Codex 첫 추출, 독립적인 원본 대조, 사용자 확인, 일정 저장까지 실행했다. 테스트 보관함과 앱 설정은 임시 디렉터리로 분리했다. 인증은 기존 앱의 Codex controller 디렉터리를 사용했으며 자격 증명을 읽거나 복사하지 않았다. IPC의 Codex 요청 경로를 같은 패키지의 실제 controller로 연결했고, 모델 응답을 대체하지 않았다.

## 테스트에서 발견해 수정한 중복

첫 실계정 테스트에서 이미지 처리와 두 번의 AI 응답은 성공했지만, 2개 일정을 4개로 저장하는 문제가 드러났다. 첫 응답의 원문에는 `LINK`/`BMS` 대상명이 붙고 대조 응답은 대상명을 별도 필드로 분리해 원문에서 생략하면서, 기존의 보수적인 보존 로직이 두 결과를 모두 남겼다.

동일한 대상 행에서 원문 앞에 공백으로 분리된 대상명이 붙은 경우만 비교에서 제외했다. 원문과 저장 데이터 자체는 변경하지 않는다. 서로 다른 대상명 단어, 단계, 날짜는 그대로 구분한다. 실제 응답으로 회귀 검사의 실패를 확인한 뒤 수정했고, 같은 응답의 재생과 새 실계정 요청 모두 정확히 2개를 저장했다.

- 전체 단위 테스트 324개, production build, diff check 통과.
- 최종 Mac 패키지의 기존 원본 대조 5개 그룹 통과: 99개 결과 검토·저장, 누락/병합 안내, 실패/취소 시 초기 결과 유지.
- 패키지 파일 273개가 소스·빌드와 일치하며 엄격한 서명 무결성 검사 통과.
- 최종 ASAR SHA-256: `43e9dda12657fa454cc48f6ff89cc2c6bd6e1d084ceab42cb517d51b0518d526`.
