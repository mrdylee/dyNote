# Agent 후속 편집과 검토 버튼 고정 검증

2026-11-19, `dynote-main` 개발 소스 기준. 기존에 진행 중이던 패널 너비·저널·문서 탭 변경은 보존했다.

## 변경 동작

- Agent는 현재 또는 다른 보관함에 미확정 초안이 있어도 질문·검색·후속 편집을 시작한다. 동시에 진행 중인 요청과 저장 작업은 계속 보호한다.
- 매 요청은 현재 초안을 기준으로 편집하며 최초 원본과 저장 버전을 유지한다. 저장 전 새 문서도 여러 요청에 걸쳐 수정한 뒤 생성할 수 있다.
- 허용된 문서 검색·읽기는 최신 초안을 사용한다. 선택 영역과 보관함 접근 권한은 유지하며, 전체 초안 목록을 모델 입력에 일괄 포함하지 않는다.
- 요청 이후 직접 편집하거나 외부 변경이 감지된 문서는 추가 AI 반영을 막고 충돌을 표시한다. 같은 요청에서 다른 문서는 계속 작업할 수 있다.
- 직접 편집한 내용은 후속 요청에 포함되며, 해당 내용을 잃을 수 있는 되돌리기는 계속 비활성화한다. 변경 유지 또는 복구본 저장으로 보존한다.
- 문서 제목과 변경 유지·변경 되돌리기·원본 비교 버튼은 각 문서 영역 상단에 고정된다. 비교 내용은 본문과 함께 스크롤한다.
- 기존 미확정 문서 5개 및 복구 크기 제한은 요청을 이어갈 때도 적용한다. Edit 모드의 별도 적용 절차는 유지한다.

## 실행 결과

- `npm run build`: 성공. 기존 대형 번들 경고가 있으며 빌드 오류는 없다.
- `npm test`: 503개 통과, 실패·건너뜀 0개.
- `scripts/verify-copilot-continuation.mjs`: 실제 Electron UI에서 9개 시나리오 통과.
- `scripts/verify-copilot-live-edits.mjs`: 기존 유지·되돌리기·중지·선택 영역·재시작 복구·외부 충돌 등 13개 시나리오 통과.
- 두 UI 검증 모두 renderer 오류 0개, 임시 프로필과 임시 보관함을 사용했다.
- 고정 버튼은 실제 휠 스크롤 후 화면 위치와 클릭 가능 여부를 읽기·편집·분할 보기 및 두 문서 나란히 보기에서 확인했다.
- 후속 편집 실패와 스크롤 버튼 이탈을 수정 전에 재현했다. 회귀 검증에서 발견한 입력 직후 전송의 저장 버전 갱신 문제도 별도 테스트로 재현하고 수정했다.

UI 실행 시 `DYNOTE_PLAYWRIGHT_MODULE`에 설치된 Playwright 모듈 경로를 지정했다.

## 검증 범위

모델 응답은 가상 IPC로 공급하고 실제 문서 도구·초안 상태·편집기·보관함 API를 검증했다. 실제 모델 호출, Windows 네이티브 실행, 설치본 교체 및 배포는 수행하지 않았다.
