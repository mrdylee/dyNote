## 검증 범위

Windows 설치 시험은 통제된 상위 버전 피드에서 같은 빌드의 Setup을 다시 적용했다. 실제 설치·재실행·데이터 보존을 검증했으며, 서로 다른 두 버전 간 전환은 포함하지 않는다. AI 전송은 시험용으로 제어했으므로 실제 모델 응답과 회사 PC의 설치 정책은 사용자 환경에서 확인해야 한다.

v0.23.9 이하에서 이번 버전으로 올릴 때는 Setup을 직접 실행한다. 자동 설치는 v0.23.10부터 지원하며, 베타 검색에는 **시험 버전도 확인** 설정이 필요하다.
