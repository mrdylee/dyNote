# Obsidian 기능 대응 현황

2026-10-28 · 개발 브랜치 `feat/native-plugin-features` · 배포 전 소스 실행 기준.

사용자가 선택한 범위는 개인 보관함에서 활성화된 커뮤니티 플러그인 11개와 기본 플러그인의 **기능을 Dynote에 직접 구현**하는 것입니다. 원본 플러그인 런타임/API 호환을 제공하지 않습니다. 전체 고급 기능 대응은 진행 중입니다.

## 원본 확인과 개인정보 범위

REA로 설치 프로그램과 플러그인 프로그램을 분석했습니다. 설치 런처는 1.12.7, 실제 실행 런타임은 1.14.5입니다. 개인 보관함의 활성 목록·프로그램 파일만 확인했고, 개인 문서·플러그인 `data.json`·인증정보는 사용하지 않았습니다. 별도 테스트 보관함에서 원본 플러그인 11개의 로딩과 대표 동작을 실제 실행했습니다. 등록 명령 360개는 전체 기능이 검증됐다는 뜻이 아닙니다. [원본 분석 기록](obsidian-plugin-inventory.md).

## 기본 기능

파일·검색·그래프·백링크·태그·속성·Canvas·Bases·복구 흐름에 더해 명령 팔레트·북마크·템플릿·문서 병합/추출·링크 미리보기·단어 수·음성 녹음/재생·별도 웹 읽기 창을 구현했습니다. 문서 병합/추출과 PDF 저장은 미리보기 및 외부 변경 검사, 보관함 밖 복구 사본을 사용합니다. PDF 편집은 암호화/서명 필드가 있는 파일을 거부합니다. 음성 검증은 합성 장치로만 수행했습니다.

Obsidian Sync 계정/서비스와의 호환은 확인되지 않았습니다. 네이티브 Git 동기화와 별개입니다. 기본 기능의 존재가 원본 모든 동작과의 완전한 호환을 뜻하지 않습니다.

## V 모델 적용

요구사항 → 원본 입력/동작/출력 → 구현 단위 → 자동 검사 → 실제 Dynote 실행의 연결을 [검증 기록](native-workflows.md)에 남겼습니다. 안전한 거부와 복구도 성공 기준에 포함했습니다. 개인 보관함에서 원본/구현 앱을 실행해 비교하지 않았습니다.

최신 전체 자동 검사는 210개 통과·실패/건너뜀 0입니다. 소스 앱의 macOS 실행 검증과 빌드가 성공했습니다. Windows EXE 최초 문서 표시 지연, Windows 상호작용, 새 패키지 설치/배포, 실제 OS 마이크 동의 화면은 아직 검증하지 않았습니다. 기존 큰 번들 경고는 남아 있습니다.
