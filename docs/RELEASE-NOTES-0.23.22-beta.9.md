# Dynote v0.23.22-beta.9 · Windows x64 시험판

- PDF 미리보기에서 휠로 페이지를 넘길 수 있습니다. Ctrl을 누른 채 위로 굴리면 확대되고 아래로 굴리면 축소됩니다.
- 보관함 PDF에서 **형광펜**을 켜고 문장을 드래그하면 선택한 색으로 바로 칠해지고 PDF 파일에 자동 저장됩니다. 손으로 그은 듯 살짝 기울어진 선은 문서를 다시 열어도 보입니다.
- PDF 백링크에서 선택한 주석으로 돌아가면 강조 위치가 화면에 표시됩니다.

Windows x64에서는 Dynote를 닫고 `Dynote-0.23.22-beta.9-windows-x64-Setup.exe`를 실행하세요.
