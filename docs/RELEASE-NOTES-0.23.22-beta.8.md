# Dynote v0.23.22-beta.8 · Windows x64 시험판

Windows 설치형 Dynote에서 PC에 보관한 설치 파일로 오프라인 업데이트할 수 있습니다. 이 기능을 처음 사용하려면 이번 릴리스의 Setup.exe를 직접 실행해 설치하세요.

이후에는 **설정 → Dynote 업데이트 → 업데이트 배포처 → 로컬 설치 파일**에서 **Setup.exe 선택**을 눌러 더 높은 버전의 Dynote 설치 파일을 지정하세요. **설치하고 다시 시작**을 누르면 작업을 저장하고 업데이트합니다.

선택한 경로는 앱을 다시 열어도 유지됩니다. 로컬 모드에서는 Git이나 인터넷에 업데이트를 조회하지 않습니다.
