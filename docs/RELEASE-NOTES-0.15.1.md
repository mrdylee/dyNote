# Dynote v0.15.1 — 저널 편집 안정화와 파일 우클릭 메뉴

- 저널을 작성할 때 자동 저장 주기마다 분류 안내가 사라졌다 나타나며 본문이 움직이던 문제를 수정했습니다. 안내 영역은 같은 높이를 유지하며 저장 후 검토 버튼이 활성화됩니다.
- 왼쪽 문서·일반 폴더에서 마우스 오른쪽 버튼을 누르면 **휴지통으로 이동**을 선택할 수 있습니다. 확인 후 문서는 기존 앱 휴지통으로 이동하며 **되돌리기**를 사용할 수 있습니다. 폴더는 하위 파일까지 **시스템 휴지통**으로 이동하며, 복구도 시스템 휴지통에서 할 수 있습니다. Journal·Templates·Attachments·_attachments와 설정된 일지·템플릿 폴더 및 이를 포함하는 상위 폴더는 메뉴에서 제외합니다.
- 저널과 일반 Markdown 문서의 기본 보기 모드를 **Live Preview**로 변경했습니다. 직접 선택한 읽기·소스·분할 보기 등은 현재 세션의 문서별 선택으로 유지됩니다.
- **분류 제안 검토**에 마우스를 올리거나 키보드로 초점을 두면 제안 선택, 저장 대상·원문 처리, 미리보기·적용 순서를 설명합니다. 설명은 본문 위에 겹쳐 표시되어 위치를 움직이지 않습니다. 확인 전에는 원문을 변경하지 않습니다.

## 설치

Apple Silicon Mac: `Dynote-0.15.1-macos-arm64.dmg`를 열고 앱을 Applications로 옮기세요. 기존 앱은 먼저 종료합니다. Mac 앱은 ad-hoc 무결성 서명이며 Apple Developer ID 배포 서명·공증은 없습니다.

Windows x64: `Dynote-0.15.1-windows-x64.zip` 전체를 풀고 `Dynote-win32-x64/Dynote.exe`를 실행하세요. resources와 DLL도 함께 유지합니다. 노트 보관함과 기존 설정은 유지됩니다.

플랫폼별 SHA256SUMS와 패키지 검증 JSON을 함께 제공합니다. 시험판 업데이트를 받으려면 앱의 베타 포함 설정을 확인하세요.

## 검증

Mac arm64·Windows x64 네이티브 CI에서 테스트·보안 검사·패키지 원본 비교와 실제 앱 시나리오를 통과한 후 공개 베타로 게시합니다. 신규 검사는 입력·자동 저장 중 위치 고정, 팝업, 기본 보기, 문서 삭제·복구, 폴더 휴지통과 보호 경계를 다룹니다. 기존 구간 편집·Bullet Threading·저널·Git·AI 검토 시나리오도 포함합니다. AI 응답은 결정적 테스트 이벤트이며 실계정 로그인이나 유료 모델 추론을 검증하지 않습니다.
