# Dynote v0.23.16 · Windows x64 및 Apple Silicon Mac

**설정 → 보관함 → 개인 노트 Git 설정 → 여러 PC에서 이어 쓰기**에서 기기 이름과 Git 저장소·브랜치를 지정합니다. 기존 ZIP 목록을 확인한 뒤 **이 설정으로 동기화**를 누릅니다. 다른 PC에서는 같은 저장소를 **기존 저장소 가져오기**로 빈 폴더에 연결할 수 있습니다.

- Cloud PC에서 쓴 Markdown을 Local PC에서 이어 쓰고, 개인 노트 폴더나 File Storage에 넣은 PDF·XLSX·PPTX·ZIP을 다른 PC에서 받습니다. 앱을 열어 두면 약 1분마다 확인하고 편집은 5분 단위로 묶습니다. 창을 떠날 때나 **지금 동기화**를 누를 때도 전송합니다.
- 같은 노트의 같은 문장을 여러 PC가 고치면 제목 옆 **버전 확인**에서 기기별 내용을 비교합니다. 세 번째 후보가 들어와도 고른 문장을 유지합니다. **나중에**로 닫아도 다른 노트는 계속 전달됩니다. 바이너리 파일은 후보별로 저장하거나 사본 이름을 정해 모두 유지할 수 있습니다.
- **버전 기록 → 이 파일만 복원**으로 보고서 한 개를 되돌릴 수 있습니다. 개인 동기화에서는 복원 직전 내용과 복원한 내용을 모두 Git에 기록합니다.
- 개인 양방향 동기화는 보관함별로 켜는 기능입니다. 파일 하나의 한도는 25 MiB입니다. 복사가 끝났는지 확인하기 어려운 첨부는 설정의 **복사 완료 확인**에서 전송할 수 있습니다.

기존 Windows 설치형은 **설정 → 업데이트 → 시험 버전도 확인 → 지금 업데이트 확인**에서 받을 수 있습니다.

Apple Silicon Mac에서는 DMG를 열고 Dynote를 응용 프로그램 폴더로 끌어 설치합니다. Mac 시험판은 ad-hoc 무결성 서명을 사용하며 Apple 공증은 받지 않았습니다.
