# Dynote v0.23.22-beta.3 · Windows x64 시험판

개인 노트의 `File Storage`와 그 하위 폴더에서 일반 파일을 확장자와 관계없이 동기화합니다. EXE를 ZIP으로 압축할 필요 없이 그대로 넣을 수 있고, 확장자 없는 파일도 전송됩니다. 파일당 한도는 25 MiB입니다.

1. 클라우드 PC와 로컬 PC 양쪽에서 **설정 → 업데이트 → 시험 버전도 확인 → 지금 업데이트 확인**을 선택하고 업데이트를 설치하세요.
2. 클라우드 PC에서 **개인 노트**를 우클릭하고 **지금 동기화**를 선택하세요. 이미 `File Storage`에 넣어 둔 파일도 전송 대상에 포함됩니다.
3. 로컬 PC에서도 **지금 동기화**를 선택한 뒤 같은 `File Storage` 폴더에서 파일을 확인하세요.

두 PC는 같은 개인 노트 저장소와 브랜치에 연결되어 있어야 합니다. Git 제외 규칙과 숨김 경로 등 기존 경로 제한은 계속 적용됩니다.
