# Dynote v0.23.10 — 백그라운드 문서 생성과 Windows 자동 업데이트

- Copilot Note 문서 경로 오른쪽의 **문서로 만들기**를 누르면 새 임시 탭이 열립니다. 생성 중에는 회전 아이콘과 탭 색상으로 진행 상태를 표시하며 다른 문서에서 계속 작업할 수 있습니다.
- 생성한 초안은 임시 보관하고 **어디에 저장할까요?**에서 폴더와 파일명을 선택합니다. 다른 문서의 미확정 Copilot 변경 때문에 새 문서 저장이 차단되던 문제를 수정했습니다. 종료 직전 편집도 저장합니다.
- 개인·팀 노트의 왼쪽 트리 우클릭 메뉴에 **폴더 추가**를 넣었습니다.
- 탭을 왼쪽 폴더로 끌면 확인 후 이동하고, **Ctrl을 누르면 복사**합니다. 같은 보관함의 문서 본문에 놓으면 내부 링크를 삽입하고 탭 미리보기가 제자리로 돌아갑니다.
- Windows 설치형 앱은 다운로드 검증 후 **문서 저장 → 종료 → 설치 → 재실행**을 지원합니다. 설정에서 자동 설치를 끄거나 **지금 설치하고 다시 시작**, **나중에**를 선택할 수 있습니다. 입력·한글 조합·AI 생성·녹음·대화상자가 끝나고 1분간 입력이 없으면 자동 설치를 시작합니다.

## 설치와 업데이트

Windows x64는 **Dynote-0.23.10-windows-x64-Setup.exe**를 실행하세요. v0.23.9 이하에는 자동 설치 기능이 없으므로 이번 업데이트는 다운로드한 Setup을 직접 실행해야 합니다. 자동 설치는 v0.23.10에서 이후 버전으로 업데이트할 때 적용됩니다.

기존처럼 베타로 게시합니다. 앱에서 찾으려면 **설정 → 업데이트 → 시험 버전도 확인**을 켜세요. ZIP 실행형은 ZIP을 다운로드하며 직접 교체합니다. Apple Silicon Mac용 DMG·ZIP과 플랫폼별 SHA-256 목록도 제공합니다. Mac 앱은 ad-hoc 서명이며 Apple 공증은 없습니다.

실제 AI 응답과 회사 PC별 설치 정책은 사용자 환경에서 확인해야 합니다. 보관함을 넘는 이동으로 내부 링크가 깨지는 경우에는 원본을 유지하고 복사를 안내합니다.
