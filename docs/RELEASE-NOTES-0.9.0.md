# Dynote v0.9.0 — 캡처에서 시작하는 개발 플래너

- PPT 일정 캡처 붙여넣기·드롭·선택 → 이미지 지원 Copilot으로 인식 → 원본과 비교·수정 → 선택 등록.
- 오늘·4주 타임라인·근거 보기, 대상별 필터, 준비 작업, 기간을 유지하는 드래그 이동과 저장 실행 취소.
- 고민에 대한 대안·이유·고려사항을 비교하고 채택/보류. 채택한 제안만 준비 작업으로 추가.
- 요구사항·설계·구현·시험·결과 노트 연결, 연결 후 변경 감지와 명시적 시험 결과.
- 보관함별 Markdown 저장, 중복 캡처 제외, 외부 수정 충돌 보호. 불명확한 연도는 미정으로 검토.

## 사용과 범위

왼쪽 **개발 플래너**에서 시작하세요. 연결된 Copilot이 있으면 붙여넣은 이미지가 자동 전송되어 분석됩니다. 인식값은 등록 전 확인해야 합니다. 자세한 저장·수정 흐름은 [사용법](DEVELOPMENT-PLANNER.md)을 확인하세요.

ubCode 0.38.0의 작은 예제에서 누락된 시험 연결 검출을 확인했습니다. 변경 영향 분석은 라이선스 제한으로 검증하지 못했으며 앱 직접 연동은 포함하지 않습니다. [평가 기록](verification/ubcode-planner.md)

Windows는 macOS에서 교차 패키징하며 실제 Windows 실행은 미검증입니다. 배포 서명·macOS 공증·자동 업데이트는 없습니다. Windows ZIP은 전체를 풀고 `Dynote-win32-x64/Dynote.exe`를 실행하세요. v0.8.0의 원본 플러그인 지원 범위는 그대로 유지됩니다.
