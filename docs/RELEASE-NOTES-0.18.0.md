# Dynote v0.18.0 — 포스트잇과 라벤더 디자인

- **Ctrl+Shift+M**을 누르면 새 포스트잇이 열립니다. 메모는 개인 보관함의 `포스트잇/` 폴더에 Markdown으로 자동 저장됩니다. 메뉴 막대 또는 알림 영역의 Dynote 메뉴에서 최근 메모를 다시 열 수 있습니다.
- 포스트잇에서도 저널처럼 불릿을 입력하고 연결선을 볼 수 있습니다. 창 크기를 조절하거나 위에 고정하면 다음에 열 때 위치와 크기, 색상과 고정 상태를 복원합니다.
- 앱 아이콘과 상단 **DyNote** 글자를 일지 만들기 버튼과 같은 라벤더 계열로 맞췄습니다. 상단 로고를 누르면 버전 정보를 확인할 수 있습니다.
- Windows ZIP에는 Windows용 Copilot 런타임을 담았습니다. Mac용 파일이 빠져 압축 파일이 작아지고 내부 경로가 짧아졌습니다.

## 설치

- Apple Silicon Mac에서는 `Dynote-0.18.0-macos-arm64.dmg`를 열고 앱을 Applications로 옮기세요. Mac 앱에 ad-hoc 무결성 서명이 적용되어 있으며 Apple 공증은 없습니다.
- Windows x64에서는 `Dynote-0.18.0-windows-x64.zip`을 통째로 푼 뒤 `Dynote-win32-x64/Dynote.exe`를 실행하세요.
- 기존 앱에서는 **설정 → 업데이트 → 시험 버전 포함**을 켜고 업데이트를 확인하세요. 플랫폼별 SHA-256 목록을 함께 제공합니다.
