# Dynote v0.22.1 — 파일 열기와 탐색기 드롭

- **파일 → 파일 열기…** 또는 왼쪽 **파일 열기** 버튼에서 파일을 선택하세요. Windows `Ctrl+O`, macOS `⌘O`도 사용할 수 있습니다.
- 탐색기/Finder에서 파일 하나를 Dynote 창에 끌어 놓으면 자동으로 임시 미리보기가 열립니다. 편집기 위에 놓아도 지원합니다.
- Markdown(`.md`, `.markdown`), Word(`.docx`), PDF, PNG/JPEG/GIF/WebP, WebM/WAV/MP3/OGG/M4A, Canvas/Bases는 각 형식의 뷰어로 읽습니다. 그 밖의 UTF-8 텍스트·설정·소스 파일은 원문을 텍스트로 표시합니다.
- 원본을 임시 폴더에 복사해 읽기 전용으로 표시합니다. 보관함과 현재 노트는 유지하며, 정상 종료 시 임시 사본을 삭제합니다.
- 일반 문서·미디어의 **원본을 기본 앱에서 열기**로 원본을 수정할 수 있습니다. 저장 후 Dynote로 돌아오면 미리보기가 갱신됩니다. **미리보기 새로고침**도 제공합니다. 소스·스크립트 등 그 밖의 텍스트 형식은 미리보기로 제공합니다.
- 한 번에 하나의 파일을 엽니다. Markdown은 고정 크기 제한이 없으며, Canvas/Bases는 8MB, 나머지는 25MB 이하를 지원합니다. 외부 문서의 상대 연결·Bases 데이터는 현재 보관함에 자동 연결하지 않습니다.
- 기존 보관함의 Word 본문 검색, 내부 노트 드래그 이동, 붙여넣기·명시적 첨부와 일반 노트·색상 기능을 유지합니다.

## 검증 범위

- 원본 바이트 보존, 임시 사본 생성·정리, 원본 교체 저장 후 갱신, 크기 제한과 잘못된 파일 거부를 단위 테스트로 확인했습니다.
- 실제 Dynote에서 메뉴·버튼·디스크 파일 드롭·취소·Markdown 표/코드·텍스트 원문·미디어·읽기 전용 Canvas/Bases를 검사합니다. Windows와 macOS 패키지의 전체 네이티브 회귀 검증 후 게시합니다.
- 실제 Microsoft Word에서의 수정·저장과 Polarion 재업로드는 별도 검증이 남아 있습니다.

## 설치와 업데이트

- Windows x64: ZIP 전체를 풀고 **Dynote-win32-x64/Dynote.exe**를 실행하세요.
- Apple Silicon Mac: DMG 또는 ZIP을 사용하세요. 기존과 같은 ad-hoc 서명이며 Apple 배포 공증은 없습니다.
- **설정 → 업데이트 → 시험 버전 포함**에서 업데이트를 확인할 수 있습니다. 플랫폼별 SHA-256 파일을 제공합니다.
