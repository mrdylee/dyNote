# Dynote v0.22.1 — Word 파일 열기와 탐색기 드롭

- **파일 → 파일 열기…** 또는 왼쪽 **파일 열기** 버튼에서 `.docx`를 선택하세요. Windows `Ctrl+O`, macOS `⌘O`도 사용할 수 있습니다.
- 탐색기/Finder에서 Word 파일 하나를 Dynote 창에 끌어 놓으면 자동으로 미리보기가 열립니다. 편집기 위에 놓아도 지원합니다.
- 원본을 임시 폴더에 복사해 제목·표·이미지를 읽습니다. 보관함이나 현재 노트를 바꾸지 않으며, 정상 종료 시 임시 사본을 삭제합니다.
- **원본을 기본 앱에서 열기**로 Word 등 운영체제에 연결된 앱에서 원본을 수정할 수 있습니다. 저장 후 Dynote로 돌아오면 미리보기가 갱신됩니다. **Word 미리보기 새로고침**도 제공합니다.
- 한 번에 하나의 25MB 이하 DOCX를 지원합니다. 기존 보관함의 Word 본문 검색과 미리보기, 일반 노트·색상 기능은 유지합니다.

## 검증 범위

- 원본 바이트 보존, 임시 사본 생성·정리, 원본 교체 저장 후 갱신과 잘못된 파일 거부를 단위 테스트로 확인했습니다.
- 실제 Dynote에서 메뉴·버튼·디스크 파일 드롭·여러 파일 안내·취소·원본 경로 전달을 검사합니다. Windows와 macOS 패키지의 네이티브 회귀 검증 후 게시합니다.
- 실제 Microsoft Word에서의 수정·저장과 Polarion 재업로드는 별도 검증이 남아 있습니다.

## 설치와 업데이트

- Windows x64: ZIP 전체를 풀고 **Dynote-win32-x64/Dynote.exe**를 실행하세요.
- Apple Silicon Mac: DMG 또는 ZIP을 사용하세요. 기존과 같은 ad-hoc 서명이며 Apple 배포 공증은 없습니다.
- **설정 → 업데이트 → 시험 버전 포함**에서 업데이트를 확인할 수 있습니다. 플랫폼별 SHA-256 파일을 제공합니다.
