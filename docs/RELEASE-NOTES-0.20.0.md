# Dynote v0.20.0 — Copilot 세션별 저널 기록

- Copilot 대화를 프로젝트 안에 세션당 Markdown 문서 하나로 저장합니다. 날짜별 저널과 **프로젝트별 기록**에서 같은 세션 문서를 열 수 있습니다. 프로젝트별 기록에서 이전 날짜를 고르면 문서의 해당 날짜로 이동합니다.
- 업데이트 후 첫 가져오기에서 기존 대화와 저널의 자동 기록 링크를 이관합니다. 이전 날짜별 문서와 그 안의 사용자 편집은 원래 경로에 보존합니다.
- 같은 세션의 완료된 새 메시지만 추가합니다. 원본 형식이 바뀌어 기존 메시지 ID를 대조할 수 없는 세션은 상태에 표시하고 보류합니다.
- 자동 기록은 앱 실행 중 1시간마다 확인합니다. 저널의 **가져오기**로 오늘 대화를 바로 가져오거나, 설정에서 과거 기간을 선택할 수 있습니다.

## 설치와 업데이트

- Windows x64에서는 ZIP을 풀고 **Dynote-win32-x64/Dynote.exe**를 실행하세요.
- Apple Silicon Mac 패키지는 ad-hoc 서명으로 배포합니다. Apple 공증 상태는 미공증입니다.
- 앱의 **설정 → 업데이트 → 시험 버전 포함**에서 업데이트를 확인하세요. 플랫폼별 SHA-256 파일을 제공합니다.
