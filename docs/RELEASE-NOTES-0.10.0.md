# Dynote v0.10.0 — ESS LINK 3D와 노트 연결

- 앱 안의 ESS LINK 3D 탭: 컨테이너 6대, 회전·확대·이동, 문·환기구 개폐, 기존 진단 목업.
- 배경색을 제거한 3D 모델 표시. 별도 서버·Unity·Blender 설치 없이 앱에 포함된 모델을 엽니다.
- 컨테이너별 랙·BPU·제어기·스위치와 기존 노트 연결·해제. 연결 노트가 하나면 3D 부품 클릭으로 바로 열기.
- 노트의 YAML에 연결 저장, 재시작·이름 변경·폴더 이동 후 유지, 외부 수정 충돌 보호와 보관함별 분리.
- 로딩 오류·그래픽 컨텍스트 손실 안내와 다시 불러오기. 3D를 보지 않을 때 렌더러 해제.

왼쪽 **ESS LINK 3D 보기** 또는 노트 상단 **ESS LINK 보기**에서 시작하세요. [사용법](ESS-3D.md)

이는 포함된 ESS 목업의 재사용이며 일반 3D 파일 가져오기나 Unity 프로젝트 실행 기능은 아닙니다. 진단 값과 Contactor 시연은 모의 데이터이며 실제 장비를 제어하지 않습니다. v0.9.0의 개발 플래너와 v0.8.0의 제한된 원본 플러그인 실행을 포함합니다.

Windows는 macOS에서 교차 패키징하고 실제 Windows 실행은 미검증입니다. 배포 서명·macOS 공증·자동 업데이트는 없습니다. Windows ZIP은 전체를 풀고 `Dynote-win32-x64/Dynote.exe`를 실행하세요.
