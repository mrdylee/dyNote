# Dynote v0.23.14 · Windows x64

- 개인 노트에서 `Copilot Note` 폴더를 삭제한 뒤 **설정 → Copilot 대화 자동 저장 → 선택한 프로젝트 가져오기**를 누르면, 원본 기록을 읽을 수 있는 대화 파일이 다시 생성됩니다.
- **설정 → 보관함**에서 연결된 개인·팀 공간별 Git 원격 주소, 브랜치와 자동 백업 대상을 볼 수 있습니다. 각 공간의 **이 공간의 Git 설정** 버튼으로 바로 이동할 수 있습니다.
- 개인·팀 보관함을 열면 파일 목록에 빈 `File Storage` 폴더가 준비됩니다. 탐색기에서 ZIP 등을 Ctrl과 함께 끌어 놓으면 복사합니다. ZIP은 개인·팀 Git 자동 백업 대상에서 제외됩니다.
- 빈 `File Storage`만 있는 보관함에서도 기존 Git 저장소를 가져올 수 있습니다. 보관 중인 파일이 있으면 가져오기를 중단합니다.

설치하려면 Dynote를 종료하고 `Dynote-0.23.14-windows-x64-Setup.exe`를 실행하세요. 기존 설치형에서는 **설정 → 업데이트 → 시험 버전도 확인**을 켜고 업데이트할 수 있습니다.
