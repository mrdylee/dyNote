# Dynote v0.23.22-beta.5 · Windows x64 시험판

**설정 → 테마**에서 색을 고르면 노트 본문과 링크, 저널 글머리표, 사이드바, 목차와 Copilot 패널에 바로 적용됩니다. 직접 지정한 글자색과 캔버스 연결선 색은 유지됩니다.

- PowerPoint 미리보기의 배경과 이동 버튼도 테마를 따릅니다. 테마를 바꿔도 보던 슬라이드와 원본의 색상은 유지됩니다.
- Copilot에서 Tab 키로 이동할 때 현재 입력란과 선택 메뉴를 진한 테두리로 확인할 수 있습니다.
- 캔버스 화살촉은 양쪽 모두 연결선과 같은 색으로 표시됩니다.

기존 사용자는 **설정 → 업데이트 → 시험 버전도 확인 → 지금 업데이트 확인**에서 설치할 수 있습니다. 처음 설치하는 경우 아래의 `Dynote-0.23.22-beta.5-windows-x64-Setup.exe`를 실행하세요.
