# Dynote v0.23.22-beta.1 · Windows x64 시험판

개인 노트를 로컬 Git 설치 없이 GitHub.com 저장소에 올리고 다른 PC에서 받을 수 있습니다.

## Windows에서 사용하기

1. `Dynote-0.23.22-beta.1-windows-x64-Setup.exe`를 실행합니다. 포터블 버전은 ZIP을 풀고 `Dynote.exe`를 실행합니다.
2. 테스트용으로 새 개인 노트 폴더를 엽니다. GitHub API 방식은 `.git`과 `.gitignore`가 없는 일반 폴더를 사용합니다.
3. 개인 노트 폴더 이름을 우클릭해 **동기화 설정**을 열고 **Git 사용 방식 → GitHub API로 이어 쓰기**를 선택합니다.
4. 테스트용 GitHub 저장소의 HTTPS 주소와 브랜치를 입력합니다. 해당 저장소의 **Contents 읽기·쓰기** 권한이 있는 토큰을 이 PC의 앱에 입력하고 **연결하고 동기화**를 누릅니다. 토큰은 Windows 사용자 계정으로 암호화해 저장합니다.
5. **동기화됨**이 표시되면 GitHub에서 테스트 노트를 확인할 수 있습니다. 다른 PC에서도 새 개인 폴더를 같은 저장소와 브랜치에 연결하면 노트가 들어옵니다.

두 PC에서 같은 노트를 서로 다르게 고치면 먼저 올라간 내용이 원래 파일에 남고, 다른 편집본은 이름에 `(충돌 …)`이 붙은 파일로 옆에 보존됩니다.
