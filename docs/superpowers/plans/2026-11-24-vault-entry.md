# 보관함 연결 화면 구현 계획

1. VaultSettings에 개인·팀 진입을 두고 상세 화면에 기존 용도 변경, 폴더 연결과 모델 추가를 배치한다. 작은 창에서 두 진입 버튼이 보이는지 확인한다.
2. GitSettings와 Electron의 연결·가져오기 경로에서 기존 origin 및 브랜치, 빈 원격, 새 PC, 공통 이력 없는 폴더를 처리한다. 확인이나 취소만으로 원격에 기록하지 않는지 확인한다.
3. 실제 임시 Git 저장소로 첫 PC 업로드와 새 PC 다운로드, 다른 로컬 노트 보호, 팀별 부분 성공을 검증한다. 기존 보관함 시나리오와 전체 테스트를 실행한다.
