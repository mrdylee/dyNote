# Copilot panel implementation plan

> Use superpowers:executing-plans inline. The user approved this scope; no new
> approval gate or subagent dispatch is needed.

**Goal:** Connect Dynote's right panel to the user's GitHub Copilot subscription.
**Architecture:** React panel → narrow IPC → app-owned SDK controller/runtime.
**Stack:** Electron, React, CodeMirror 6, pinned @github/copilot-sdk 1.0.23.

- [x] Add failing tests in `tests/copilot.test.mjs` for bounded context, CRLF
  offsets, stale proposal rejection, safe session configuration, streaming,
  cancellation and cleanup. Run `node --test tests/copilot.test.mjs`.
- [x] Implement `core/copilot.mjs` for request/context validation and pure edit
  application; implement `electron/copilot-controller.mjs` for SDK lifecycle,
  status/models, SDK browser login, bounded events and temporary sessions.
  Validate that no SDK tool has filesystem or command permission.
- [x] Add trusted IPC to `electron/main.mjs` and `electron/preload.cjs`.
  Cancel work on vault switching and shutdown; do not make chat part of the
  file-mutation lock or Git queue.
- [x] Add `src/CopilotPanel.jsx`, panel tabs in `src/App.jsx`, compact responsive
  styles in `src/styles.css`, editor selection callback in `src/Editor.jsx`.
  Proposal application checks the original full content and uses the editor
  transaction/SaveQueue; never call a new filesystem write endpoint.
- [x] Add runtime checks for login/offline states, response streaming and stop,
  disabled/stale apply, CRLF selection, undo, vault reset and small windows.
  Run `npm test` and `npm run build`, inspect a real Electron screenshot.
- [x] Package a separate local macOS build with native SDK assets unpacked.
  Start the packaged SDK with an isolated profile. Record what was verified and
  what still requires user authentication; document setup in `docs/COPILOT.md`.
- [x] Review the final diff, fix defects, repeat affected checks and make a local
  commit. Report the app path and publication/Windows/account verification limits.

Verification evidence: `docs/verification/copilot-runtime.json`,
`docs/verification/copilot-package.json`, and
`docs/verification/COPILOT-REVIEW.md`. Live user authorization/model responses
and native Windows execution remain unverified; these limits are documented.
