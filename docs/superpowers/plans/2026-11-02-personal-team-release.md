# v0.14.0 공개 베타 배포

사용자 지시: 보안 의존성을 수정한 뒤 배포를 진행한다. 현재 작업 폴더를 유지하고, 무관한 미커밋 문서는 배포 커밋에 포함하지 않는다. 기존 공개 태그·파일은 교체하지 않는다.

1. 버전·릴리스 안내·CI를 준비한다. 확인: v0.14.0 manifest/lock 일치, 전체 audit 0, 단위 테스트와 로컬 Mac 패키지 검사 통과.
2. 전용 release 브랜치를 push한다. 확인: 동일 커밋의 Mac arm64/Windows x64 네이티브 테스트·패키지 비교·압축 파일 검사 후 CI가 새 공개 prerelease를 게시한다.
3. 공개 배포 파일을 다시 내려받는다. 확인: 공개 상태·태그 SHA·자산 5개, 모든 SHA-256·ZIP CRC·DMG·Mac 서명·ASAR 버전/소스 일치. 검사 결과를 기록한다.

Mac은 기존과 같은 ad-hoc 베타로 배포하며 Apple 공증 제한을 명시한다. 사용자 설치 앱 교체·계정 로그인·유료 추론은 이 배포 작업에 포함하지 않는다.
