# Git으로 전달하는 Cloud Copilot Ask

0.23.19의 단일 사용자 PoC다. Local D-Note의 기존 Copilot 탭에서 질문을 쓰고, Cloud D-Note가 실행한 답변을 같은 탭에서 읽는다.

## 전달 방식

전용 Git 저장소 방식은 양쪽의 Git 읽기·쓰기만 필요하다. Actions 방식은 Runner와 API가 추가로 필요하고, 문서 동기화 방식은 문서 권한과 revision을 먼저 맞춰야 한다. 이번에는 한 사용자, 한 Local, 한 Cloud Worker, 질문 한 건씩을 지원한다.

Local에는 관리자가 승인한 채널 설정을 배포한다. 설정은 Cloud 쪽 실행 신원과 짝지으며, Copilot 인증은 Cloud D-Note에 둔다. 사용자는 Local 패널에서 질문을 입력하고 전송한다. 질문 외에 문서·이력·초안·이미지·도구 접근을 전송하지 않는다. Git 쓰기 권한과 역할을 분리하고 요청과 응답은 서로 다른 키로 서명한다. 경로나 작성자 문자열로 보낸 사람을 식별하지 않는다.

Local은 한 번 만든 요청 ID를 디스크에 보관하고 전송·대기·실행·종료 상태를 표시한다. Worker는 서명, 채널, 요청 ID, 크기와 기한을 확인한 뒤 실행 선점을 Git에 게시한다. CopilotController의 Ask를 사용하고, 응답이 오면 요청 digest와 묶어서 게시한다. 끊겨도 같은 요청을 다시 조회하고, 이미 선점된 요청을 재추론하지 않는다. 패널을 닫았다 열어도 마지막 작업을 볼 수 있다.

## 검증과 운영

임시 Git 저장소와 별도 키 두 쌍으로 실제 Git 왕복, 잘못된 서명과 중복 처리, 응답 복구를 검증한다. 기존 Direct 흐름과 빌드도 확인한다. Cloud D-Note가 켜져 있는 동안 Worker가 동작한다. 회사 시험 저장소·키 배포·접근 통제·보존 기간 승인과 실제 Windows Copilot 추론은 별도 인수 검사다.
