# 개인·팀 노트 보관함 진입

보관함 첫 화면에서 개인 노트와 팀 노트를 각각 한 줄로 연다. 각 줄은 현재 연결 상태를 보여준다. 기존 용도 미지정 폴더는 사용자가 직접 분류할 수 있다.

개인 폴더를 선택하면 로컬로 열고, 사용자가 동기화를 시작할 때만 Git을 설정한다. 기존 설정이나 로컬 origin과 브랜치가 있으면 확인 가능한 값을 제안한다. 첫 PC는 비어 있는 개인 Git 저장소에 기존 노트를 올릴 수 있다. 다른 PC는 원격 주소와 기기 이름을 입력하고 빈 폴더를 한 번 선택해 같은 노트를 받는다. 관련 없는 로컬 노트와 원격 기록이 모두 있으면 자동 연결을 중단하고 빈 폴더 가져오기를 안내한다.

팀 노트에는 기존 모델과 모델 추가를 표시한다. 팀이 없는 경우 추가 화면에서 시작한다. 로컬 폴더 또는 Git 저장소를 연결할 수 있으며 일괄 등록 중 실패한 항목만 재시도한다.
