# Copilot 기록 폴더 전체 가져오기

사용자가 선택한 기록 폴더의 완료된 대화를 과거 날짜까지 모두 개인 노트에 저장한다. 프로젝트와 세션 체크박스, 세션 불러오기 버튼은 제거한다. 폴더 선택 직후 가져오고, 이미 연결한 폴더는 전체 대화 가져오기 버튼으로 다시 가져온다. 설정을 여는 것만으로 기존 선택 범위를 확대하거나 노트를 저장하지 않는다.

자동 저장 설정을 적용하면 모든 프로젝트를 대상으로 하고 이후 생기는 프로젝트도 같은 기록 폴더에서 발견한다. 기존 시간당 실행 주기와 활성화 이후 수집 기준은 유지한다. 기존 선택형 설정은 사용자가 새 설정을 적용하거나 전체 가져오기를 요청하기 전까지 보존한다.

화면에서 세션 목록을 자동으로 선택한 뒤 여러 번 요청하는 방식보다, 기존 가져오기 컨트롤러에 명시적인 전체 범위를 전달하는 방식이 단순하고 조회와 저장 사이 변경에도 일관된다. 별도 확인 버튼을 의무화하는 방식 대신 사용자가 요청한 폴더 선택 직후 저장 방식을 사용한다.

세션별 원본 경로, 저널 링크, 중복 방지, 삭제 제외, 기존 기록 이관, 실패 시 재시도 동작은 보존한다. 읽을 수 없는 개별 기록은 오류를 알리고 정상 기록은 가져온다. 개인 노트의 미확정 Copilot 편집은 유지 또는 되돌리기 전까지 가져오기를 막는다. Windows/WSL 실제 사용자 데이터에 접근하거나 배포하는 작업은 포함하지 않는다.
