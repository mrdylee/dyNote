# Dynote 포스트잇

- 메인 창 닫기는 기존 저장 확인 후 창을 숨긴다. 메뉴 막대의 Dynote 열기와 종료는 메인 창 복귀와 저장 후 앱 종료를 담당한다.
- 전역 `Ctrl+Shift+M`과 메뉴 막대의 새 포스트잇은 바로 입력할 수 있는 작은 창을 각각 만든다. 설정의 단축키 항목에 키와 동작을 표시한다.
- 새 카드는 열려 있는 카드와 다른 파스텔색을 우선 선택하고, 포인터가 있는 화면의 오른쪽 위에서 빈자리를 찾는다. 공간이 부족하면 카드 상단이 보이도록 어긋나게 배치한다.
- 카드에는 본문, 핀, 닫기, 저장 상태를 둔다. 내용 입력 후 잠시 멈추거나 창을 닫을 때 장마다 `포스트잇/` 안의 고유한 Markdown 파일을 저장한다. 기존 메모를 수정하면 같은 파일을 갱신한다.
- 개인 보관함을 우선한다. 개인 보관함을 지정하기 전에는 현재 용도 미지정 보관함을 사용한다. 최근 목록은 카드의 첫 줄로 표시한다. 기존 카드를 다시 열면 파일의 본문과 메모별 색, 좌표, 핀을 복원한다.
- 기존 Vault API로 파일의 리비전과 복구 사본을 관리한다. 저장에 실패하면 카드에 원인을 표시하고 본문을 유지한다. 앱 재시작 후에는 메뉴 막대의 최근 포스트잇에서 카드를 다시 열 수 있다.
