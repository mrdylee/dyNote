# Copilot 중계 Git 설정

설정에 앱 전체가 사용하는 ‘Copilot 중계 Git’을 추가한다. 보관함마다 적용되는 백업·복원 화면의 주소와 혼동하기 쉬우므로 독립 탭을 사용한다. 승인된 저장소와 PC 역할, 현재 적용한 주소를 표시한다. 관리자 설정이 없는 PC에는 준비 방법을 표시한다.

기존 관리 정책의 `remote`가 기본 주소다. 관리자가 선택적으로 `additionalRemotes`에 지정한 전용 HTTPS 주소도 두 PC의 설정에서 선택할 수 있다. 주소 변경은 이 PC의 사용자 프로필에만 저장하며 양쪽에서 같은 저장소를 선택해야 한다. 관리 정책과 서명 키는 Electron 메인 프로세스가 읽는다. 일반 설정 화면에서 임의의 주소를 추가하는 방식은 회사의 승인 범위를 표현할 수 없어 제외했다.

기존에 연결된 노트 저장소와 중복된 주소에는 중계를 시작하지 않는다. 역으로 새 노트 백업, 가져오기, 팀 연결에서도 중계용 주소를 거른다. 활성 요청이나 게시 대기 중인 결과가 있는 동안에는 경로 변경을 거부한다. 저장소별 작업 이력과 캐시는 기존 격리 방식을 사용한다.

서명된 합성 질문이 선택한 저장소만 통과하는지, 재시작 후 선택 복구, 기존 단일 정책, 충돌과 오류 상태를 확인한다. 기존 GitHub 시험 릴리스 경로에서 Windows x64 설치본과 Apple Silicon Mac 앱을 검증·배포한다.
