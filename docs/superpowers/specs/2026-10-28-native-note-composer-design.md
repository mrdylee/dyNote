# Native note composition and link preview

Parent scope: native equivalents of enabled core Note Composer and Page Preview. Original controlled `note-composer.mergeFile(target,source,'append')` completed, removed the synthetic source, merged source scalar properties over target values, combined tag arrays in target/source order, and appended source body after the target. Recovery was provided by the original app's trash behavior.

Native composition uses serialized Vault.documentSnapshot/applyDocumentChanges operations. Revision checks cover document bytes and supported attachment paths; recovery copies only affected documents, without reading unrelated media bytes. Preview shows every changed/created/removed Markdown or Canvas file. Apply recaptures/recomputes and rejects external document/path changes. Existing file/path/symlink/size limits remain. Extract selection or a heading section into a new file with link/embed/empty replacement; merge into an existing file with append/prepend. New extraction targets never overwrite. Source metadata remains during extraction; merge scalar properties use observed source precedence, arrays combine uniquely, target comments/body are preserved where representable. Before/after snippets make these choices inspectable.

Rebase moved local links to their new document location. Redirect merge incoming links and extracted heading/block links to the new destination; preserve aliases, labels, reference definitions, fragments and fenced/inline-code examples. Resolve alias targets through the existing knowledge model. Bound Markdown results to the existing 8MB limit. Recovery preserves full pre-operation files; do not claim crash/power-loss atomicity beyond the existing rollback/recovery mechanism.

Native Page Preview shows a delayed read-only preview when hovering resolved note links in reading or live mode, plus an explicit Open action. Reuse existing Markdown rendering/sanitization with tasks disabled; do not execute embedded code or fetch remote media. Cancel timers on document/vault/modal changes/unmount. Unresolved/ambiguous/external links do not open previews.

V-model: original merge fixture -> metadata/link/heading/extraction tests -> real temporary vault preview/apply/recovery and stale-change refusal -> actual Electron selection/heading extraction, merge and hover/open behavior. User personal vault contents are not used for verification.
