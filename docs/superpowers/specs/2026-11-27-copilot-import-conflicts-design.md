# Copilot 가져오기 충돌 해결

사용자가 직접 시작한 가져오기가 개인 동기화 충돌로 보류되면 해당 파일의 기존 버전 비교 창을 연다. 파일 경로와 보류 이유를 보여주고 첫 번째 겹친 구간으로 이동한다. 여러 파일이면 현재 순서를 표시한다. 각 선택은 명시적으로 적용해야 한다. 삭제 버전을 선택하면 이번 가져오기를 중단해 방금 삭제한 파일이 즉시 복구되는 일을 막는다.

나중에를 누르면 가져오기 화면에서 남은 충돌을 다시 열 수 있다. 마지막 파일을 해결하면 같은 보관함과 프로젝트 선택으로 재시도한다. 다른 기기에서 이미 해결한 경우에도 이어갈 수 있다. 백그라운드 수집은 팝업을 자동으로 열지 않고 해결 버튼을 표시한다. 이미 삭제가 확정된 파일은 충돌 목록에서 제외한다.
