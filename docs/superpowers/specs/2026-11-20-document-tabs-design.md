# 문서 생성 탭과 드래그

- Copilot 대화의 문서 경로 행 오른쪽으로 `문서로 만들기`를 이동한다.
- 버튼은 독립된 임시 탭을 연다. 기존 프롬프트와 모델 선택을 유지하며 생성은 탭 전환과 무관하게 계속된다. 실행 중 탭 전체 색상과 회전 아이콘으로 상태를 표시한다.
- 임시 초안은 앱 데이터의 `tmp/copilot-documents`에 저장한다. 생성 완료 후 탭 안에서 `어디에 저장할까요?`를 표시하고 원본 보관함 내 폴더와 파일명을 선택한다. 다른 탭으로 이동했으면 포커스를 빼앗지 않는다. 저장 실패와 이름 충돌 시 초안을 유지한다.
- 새 문서 저장에는 전역 Copilot 초안 검사나 flush가 필요하지 않다. 대상 파일의 미확정 초안과 기존 파일 충돌만 검사한다. 다른 파일의 AI 변경은 그대로 둔다.
- 개인/팀 보관함 제목, 트리 빈 공간, 폴더 및 문서 우클릭 메뉴에서 폴더 추가가 가능하다. 문서는 부모 폴더, 폴더는 그 안, 제목/빈 공간은 루트를 대상으로 한다.
- 탭을 트리로 드래그하면 기본 이동, Ctrl 복사다. 모든 이동은 출발/도착을 보여주는 `이동할까요?` 확인 후 실행한다. 다른 보관함으로 이동은 복사 검증 후 원본을 복구 가능한 휴지통으로 보낸다. 실패 시 원본을 보존한다.
- 탭을 Markdown 본문에 놓으면 해당 위치에 내부 링크를 삽입한다. 읽기 모드에서는 본문 끝에 삽입한다. 성공한 드롭만 탭 미리보기를 원래 탭으로 복귀시키며 원래 탭은 유지한다. 모션 감소 설정을 존중한다.
- 기존 트리→문서 분할 보기 동작은 유지한다. 다른 보관함의 내부 링크는 현재 링크 해석기가 지원하지 않으므로 명확하게 안내하고 삽입하지 않는다.

검증: 실제 임시 파일, 충돌 보존, 폴더 경로 보안, 전역 미확정 변경이 있는 상태의 저장, 생성 도중 탭 전환, Ctrl 복사/이동 취소/확인, 본문 링크와 복귀 애니메이션을 임시 프로필 Electron에서 확인한다. 실제 AI 서비스와 Windows 설치 검증은 별도로 구분한다.
