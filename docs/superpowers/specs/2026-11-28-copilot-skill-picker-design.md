# Copilot Agent 스킬 직접 선택

직접 연결된 Copilot Agent의 기존 입력창에서 사용자가 공백 또는 줄 시작 뒤에 달러 기호를 입력하면 등록한 스킬의 이름과 설명을 검색한다. 문서 첨부와 같은 키보드 조작과 클릭을 사용한다. 선택하면 질문 위에 스킬 하나가 표시되며 전송 전 해제할 수 있다. 성공한 요청에서 선택을 소모하고 실패 시에는 재시도를 위해 유지한다.

렌더러에는 목록의 이름·설명·경로만 전달한다. 메인 프로세스는 해당 요청 시점의 등록 목록에서 이름과 경로를 다시 확인한 뒤 SKILL.md 내용을 Copilot에 전달한다. 등록이 해제되었거나 다른 폴더의 동명 스킬로 바뀌면 사용자에게 다시 선택하도록 알린다. 보내는 메시지와 최근 대화에는 사용한 스킬 이름을 표시한다.
