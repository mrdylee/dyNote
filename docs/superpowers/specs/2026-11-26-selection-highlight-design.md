# 선택 영역 미니 메뉴와 노란 형광펜

편집 보기와 Live Preview에서 회의록의 문구를 선택하면 그 자리에서 강조할 수 있다. 미니 메뉴의 굵게, 글자색, 크기는 기존 명령을 재사용한다. 노란 형광펜과 형광펜 지우기를 별도 버튼으로 제공한다. 상단 도구 모음에서는 기존 적용 범위 규칙에 따라 현재 줄도 강조할 수 있다.

선택 끝 근처에 메뉴를 표시하고 공간이 부족하면 위치를 바꾼다. 선택을 해제하거나 Esc를 누르거나 편집 영역을 떠나면 닫는다. 읽기 전용 문서는 강조 결과만 표시한다. 여러 줄을 선택해도 목록 표식과 코드 블록을 보존한다.

형광펜은 노트 본문에 허용된 단일 배경색 스타일로 저장한다. 글자색, 크기, 굵기와 함께 쓸 수 있고 지우기는 배경색만 제거한다. 한 번의 실행 취소로 직전 편집을 복구한다. 새 색상이나 전용 단축키를 정하는 것은 후속 범위다.

검증은 원문, 읽기 보기, Live Preview, 파일 재열기의 결과를 비교한다. 실제 앱에서 선택한 구절이 버튼 클릭 중 유지되고 메뉴가 선택 해제와 Esc에 반응하는지 확인한다.
