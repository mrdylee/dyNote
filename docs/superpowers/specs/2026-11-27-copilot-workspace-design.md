# Copilot 문서 첨부와 대화 복원

직접 연결된 Copilot 패널의 질문창에서 # 뒤에 문서 이름을 입력하고 제안을 선택하면 현재 보관함의 참고 문서로 첨부한다. 키보드와 마우스로 선택하며, 기존 첨부 한도와 전송 규칙을 공유한다.

최근 대화는 보관함별로 로컬 앱 데이터에 보관한다. 새 대화를 시작하거나 앱을 재시작한 뒤에도 사용자가 목록에서 대화를 열어 후속 질문을 보낼 수 있다. 원본 이미지와 인증 정보는 대화 기록에 저장하지 않는다.

완료된 답변마다 대화 복원 지점을 표시한다. 이전 답변의 복원 지점을 선택하면 그 답변까지의 대화를 남긴다. 다음 요청과 앱 재시작 이후에도 같은 대화를 이어간다. 파일과 초안은 복원 대상에 포함하지 않는다.

Agent 확장 관리에서는 기존 파일 선택기를 통해 Skill 폴더와 MCP JSON을 등록하고 연결 목록을 확인하거나 해제한다. 원본 파일은 보존한다.
