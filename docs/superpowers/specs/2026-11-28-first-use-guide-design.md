# Dynote 첫 사용 안내

새 설치에서 예제 보관함을 열면 오늘의 저널 자리에서 개인 폴더 연결, 다른 PC의 노트 가져오기, 팀 노트 연결, 예제 문서 열기를 제공한다. 기존 개인·팀 공간의 시작 화면과 복원된 작업은 유지한다. 설정의 시작 화면에서 다시 열 수 있다.

개인 폴더 선택은 기존 보관함 전환을 사용한다. 성공한 사용자에게 오늘의 저널에 한 줄을 써보라는 말풍선을 보여준다. 그 저널의 편집분이 디스크에 기록된 뒤 저장 위치와 개인 동기화 설정을 안내한다. 닫거나 완료한 안내 상태는 기기에 저장한다. 폴더 선택 취소나 저장 실패를 완료로 표시하지 않는다.

가져오기와 팀 연결은 기존 설정의 해당 양식을 직접 연다. 가져오기는 기존 저장소에서 빈 폴더로 받는 동작임을 표시한다. 개인 Git 설정은 일일 백업과 여러 PC에서 이어 쓰기의 목적을 설명하고, 업로드할 노트와 기존 노트를 받을 때 사용할 동작을 구분한다. 로그인, 인증, 저장, 동기화 엔진은 기존 구현을 호출한다.

검증은 빈 프로필에서 첫 화면, 선택 취소, 개인 폴더 연결, 실제 저널 입력과 저장, 다시 시작, 가져오기와 팀 양식 진입, 예제와 안내 다시 열기를 확인한다. 실제 원격 저장소에 노트를 전송하지 않고 목적지와 버튼 동작을 검증한다.
