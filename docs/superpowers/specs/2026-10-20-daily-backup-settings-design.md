# 일일 Git 백업, 설정과 보관함, 날짜별 복원

2026-10-20. 사용자 요청: 로컬 자동 저장 유지, Git 하루 한 번 및 누락한 백업의 시작 시 재개, 설정 메뉴, 지속되는 보관함 관리, 캘린더에서 Git 백업 복원.

## 동작

- 로컬 저장 큐와 700ms 저장 동작은 유지한다.
- 기존 분 단위 Git 설정은 일일 백업으로 전환한다. 우선 로컬 시간 23:00을 예약 시각으로 사용한다. 어제의 예약 백업이 빠졌으면 시작 시 현재 디스크 내용을 백그라운드 백업한다. 누락한 날짜마다 가짜 커밋을 만들지 않는다.
- 자동 백업은 보관함별, 이 PC의 로컬 날짜별 최대 한 번 새 커밋을 만든다. 시작 시 보충 백업도 오늘 횟수에 포함한다. 수동 '지금 Git 저장'은 예외다.
- 성공 여부와 별개로 커밋 생성 날짜 및 전송 대기 커밋을 저장한다. 전송 실패 재시도는 기존 커밋을 보내며 그동안의 새 편집으로 커밋을 늘리지 않는다. 연결 해제 시 재시도도 멈춘다.
- 백그라운드 예약/시작 작업은 창 표시를 네트워크 응답 때문에 막지 않는다. 내용이 같으면 빈 커밋은 만들지 않는다. 앱 종료 중 원격 작업 완료를 보장하지 않는다.
- 설정 메뉴 및 Cmd/Ctrl+,에서 보관함, 글꼴, Git 백업, 백업 복원 탭을 연다. 기존 글꼴 선택 기능을 그대로 옮긴다.
- 설정 파일은 기존 앱 데이터 `Open Notes` 경로를 유지한다. 기존 `vaultRoot`를 등록 목록으로 이관하고 마지막 선택을 원자적으로 기록한다. 목록 제거는 실제 폴더 삭제가 아니다.
- 시작 때 선택한 폴더가 없어지거나 읽을 수 없으면 선택 경로와 오류를 표시하고 보관함 재선택을 제공한다. 다른 예제 폴더로 조용히 전환하지 않는다.

## 복원

- 선택한 보관함의 로컬 Git 이력을 월별로 조회한다. 원격 저장소를 아직 가져오지 않았다면 기존 Git 복제 기능으로 먼저 가져온다. 캘린더 날짜는 PC 로컬 시간의 커밋 날짜다.
- 한 날짜에 여러 기록이 있을 수 있으므로 시간, 제목, 짧은 커밋 ID를 고른다. 아직 원격 업로드되지 않은 로컬 커밋도 존재할 수 있음을 표시한다.
- 복원 전 추가/수정/삭제 파일 목록을 보여준다. 미저장 초안을 먼저 저장하고, 미리보기 이후 파일이 바뀌면 재확인을 요구한다.
- 복원 전 현재 지원 파일 전체를 보관함 밖 복구 폴더에 복사한다. Markdown, Canvas, Bases, 이미지, PDF만 복원하고 `.git`, 미지원 파일, 설정은 건드리지 않는다. 경로 이탈, 심볼릭 링크, 특수 파일은 차단한다.
- Git reset, rebase, 강제 push는 하지 않는다. HEAD와 기존 이력은 유지하고 작업 폴더 내용만 선택한 백업으로 바꾼다. 복원된 내용은 다음 백업 또는 수동 저장에서 새 커밋이 된다.
- 복원과 앱 저장/Git 백업은 직렬화한다. 쓰기 전 파일 revision을 재검사하며 실패 시 앱이 변경한 파일을 가능한 범위에서 되돌리고 복구 위치를 알려준다. 다른 프로세스의 동시 편집을 무조건 원자적으로 막을 수 있다고 주장하지 않는다.

## 범위와 검증

실제 사용자 보관함과 원격에는 테스트 변경을 하지 않는다. 임시 폴더와 로컬 bare Git으로 날짜 전환, 재실행, 누락 보충, 실패 후 중복 없는 재전송, 설정 이관, 누락 폴더, 과거/빈/바이너리 복원, 경로/이력/스테이징 보호를 검증한다. 실제 Mac Electron에서 메뉴·설정·보관함 재실행·캘린더 선택·복원 전후 내용을 확인한다. Windows 실제 실행 여부는 별도로 보고한다. 이 작업은 새 릴리스 게시 요청을 포함하지 않는다.
