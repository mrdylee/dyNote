# 동기화된 스티키 노트 열기

개인 보관함의 포스트잇 폴더에 도착한 Markdown 문서를 왼쪽 탐색기 하단 목록에 표시한다. 개인 공간을 아직 지정하지 않은 경우 기존 단축키처럼 활성 미지정 보관함을 사용한다. 팀 문서는 제외한다.

접은 상태에서도 제목, 개수, 새 메모 버튼이 보인다. 펼치면 최근 수정한 순서로 첫 줄을 표시한다. 항목을 선택하면 같은 파일을 스티키 창으로 열고, 다시 선택하면 열린 창에 초점을 준다. 기존 창의 위치, 색, 핀은 기기에 보관한다. 닫은 뒤에도 목록에 남는다. 목록과 카드의 ＋는 기존 단축키와 같은 빈 카드를 연다.
