# Copilot 저널 자동기록

2026-11-04. 사용자가 MCP를 보류하고 자동 저널 기록과 제목 옆 삭제 버튼을 요청했다. 이 문서가 기존 MCP 검토안의 구현 범위를 대체한다.

## 구현 범위

VS Code 로컬 workspaceStorage에서 선택한 프로젝트의 chatSessions JSON/JSONL 및 Copilot transcripts JSONL을 읽는다. 별도 VS Code 확장/Hook 설치와 MCP 서버는 만들지 않는다. 개인 보관함에서만 활성화할 수 있고 프로젝트 선택과 활성화 시각을 저장한다. 활성화 전 요청, 숨겨진 메시지, 내부 추론, 도구 출력, 첨부 바이너리는 자동 수집하지 않는다. 원본 대화 파일은 수정하지 않는다. 지원하지 않는 형식은 오류로 표시한다.

프로젝트·현지 날짜별 대화 문서와 저널의 관리되는 링크를 만든다. 세션은 문서 안에서 구분하며, 새 세션도 프로젝트 설정을 따른다. 표준 저장 파일이 비어 있고 대응하는 transcript가 있으면 해당 transcript를 사용한다. 같은 세션의 중복 원본은 하나만 반영한다. 주기 갱신은 앱이 실행 중이고 입력/다른 저장 작업이 없을 때 수행한다. 기존 초안은 보존하고 안전한 저장 큐·revision 검사·recovery를 사용한다. 외부 편집과 충돌하면 덮어쓰지 않고 알린다.

저널 피드와 저널 편집 화면에 관리되는 AI 기록 제목 및 삭제 버튼을 표시한다. 프로젝트 묶음 삭제는 해당 날짜의 문서와 링크를 함께 휴지통으로 옮긴다. 개별 대화 삭제는 다른 세션을 유지한다. 삭제 제외 상태는 먼저 저장해 재수집과 재시작 후 재등장을 막는다. 복구 사본과 실행 취소를 제공한다. VS Code 원본과 과거 Git 커밋은 삭제하지 않는다.

저널 자동기록 설정에서 개인 공간, 원본 폴더, 프로젝트, 활성 상태와 오류를 보여 준다. 표준 macOS/Windows/Linux 로컬 경로를 지원하며 원격 WSL/SSH/Cloud는 자동 지원으로 표시하지 않는다. 기본 비활성 상태이며 실제 사용자가 대상 프로젝트를 선택해 켠다. 정식 기록은 기존 Git 백업 정책을 따른다고 표시한다.

## 검증

합성 소스에서 JSON/JSONL patch 복원, SDK transcript, 진행 중 응답 제외, 동일 문장 반복, 날짜 경계, 선택 범위, 재시작과 중복 수집을 검증한다. 임시 개인/팀 보관함으로 활성화 경계, 문서와 링크 생성, 사용자 문장 보존, 제목 삭제/되돌리기, 재수집 제외, 원본 불변, symlink 이탈과 stale vault를 검증한다. native Electron에서 설정 및 폴링/제목 삭제/재실행을 확인한다. 전체 테스트와 빌드 후 코드 리뷰로 수정하고 로컬 패키지를 검증한다. 공개 배포는 이번 요청 범위에 포함하지 않는다.

사용자는 가져오기 버튼도 요청했다. 저널 상단의 가져오기는 자동 기록 상태와 별개로 선택한 프로젝트의 오늘 대화를 반영한다. 과거 날짜 전체를 일괄 등록하지 않고, 삭제 제외와 중복 판정은 자동 수집과 공유한다.
