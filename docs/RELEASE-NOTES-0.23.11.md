# Dynote v0.23.11 — Copilot 독립 세션

- Copilot Note에서 문서 초안을 만드는 동안 별도 세션에서 Agent에게 요청을 보낼 수 있습니다. 한 작업을 중지해도 다른 세션은 계속 실행됩니다.
- 미확정 초안이 있는 문서에서도 Agent와 Edit를 이어서 사용할 수 있습니다. Edit 수정안을 기존 초안에 적용한 뒤 **변경 유지**를 누르면 문서에 저장됩니다.

## Windows x64 설치와 업데이트

기존 Dynote를 종료한 뒤 `Dynote-0.23.11-windows-x64-Setup.exe`를 실행하세요. 같은 Windows 사용자 계정으로 업데이트하면 기존 노트, 설정, 미확정 Copilot 초안을 이어서 사용할 수 있습니다. v0.23.10 설치형 앱은 **설정 → 업데이트 → 시험 버전도 확인**을 켜면 앱에서 설치할 수 있습니다. ZIP 실행형도 제공합니다.
