# ESS LINK 3D와 노트 연결

왼쪽 육면체 아이콘 **ESS LINK 3D 보기**, 명령 팔레트의 같은 명령, 또는 노트 상단 **ESS LINK 보기**로 엽니다. 모델과 뷰어는 앱에 포함되어 있어 별도 Unity·Blender 설치, 서버 실행, 인터넷 연결이 필요하지 않습니다.

## 보기와 조작

- 시작 화면은 컨테이너 6대입니다. 번호 또는 모델을 누르면 해당 컨테이너를 자세히 봅니다.
- 왼쪽 드래그로 회전, 휠이나 +/−로 확대·축소, 오른쪽 드래그로 이동합니다.
- 문을 클릭하거나 전체 열기·닫기, 환기구 버튼을 사용합니다. 랙 양문과 이웃 문 접촉 제한은 기존 ESS 웹 뷰어의 동작을 사용합니다.
- 배터리 랙·내부 패널·LCS·eBSC·스위치 버튼으로 상세 위치를 볼 수 있습니다.
- 3D 배경색은 없으며 Denote의 기본 바탕 위에 모델을 표시합니다. 진단 패널은 가독성을 위해 별도 카드로 표시합니다.
- 작은 창에서는 노트 연결 패널이 아래에 배치되며, 필요한 영역을 스크롤할 수 있습니다.

## 노트 연결

1. 3D 장치나 오른쪽/아래의 **컨테이너·부품**을 선택합니다.
2. **노트 검색**에서 찾고 **연결할 노트 선택 → 노트 연결**을 누릅니다. 아직 노트가 없다면 일반 새 문서 기능으로 먼저 만듭니다.
3. 연결된 노트가 하나면 3D 부품이나 장치 표식을 클릭할 때 그 노트가 열립니다. 여러 개면 관련 노트 목록에서 선택합니다. 연결할 때 원치 않는 자동 이동이 생기지 않도록 컨테이너·부품 드롭다운 선택은 노트를 자동으로 열지 않습니다.
4. 노트 상단 **ESS LINK 보기**는 연결된 첫 대상을 다시 보여줍니다. 3D 탭으로도 돌아갈 수 있습니다.
5. **연결 해제**는 해당 연결만 제거하며 노트 본문을 지우지 않습니다.

컨테이너·RACK 01~06·BPU 01~06·LCS·eBSC·Switch·Extended Switch를 구분합니다. ESS 01의 RACK 01과 ESS 02의 RACK 01은 서로 다른 대상입니다.

연결은 노트의 YAML 속성에 저장합니다.

```yaml
ess_links:
  - ess-02/rack-01
  - ess-02/lcs
```

일반 Markdown이므로 이름·폴더를 바꾸어도 연결은 노트와 함께 유지됩니다. 다른 속성·주석과 본문은 유지하며, YAML 표시 형식은 라이브러리 직렬화에 따라 공백이 정리될 수 있습니다. 외부에서 문서를 바꿨다면 연결 저장을 거부하고 외부 파일을 보존합니다. 문서 새로고침 후 다시 연결하세요. YAML이나 기존 `ess_links`가 잘못된 경우에도 자동으로 덮어쓰지 않습니다.

## 범위

이 기능은 포함된 ESS 목업과 노트를 연결합니다. 임의 `.blend`·Unity 프로젝트·GLB 가져오기는 포함하지 않습니다. 문은 시각화용 동작이며 표시되는 온도·SOC·진단·Contactor 예제는 모의 데이터입니다. 실제 장비에 연결하거나 제어하지 않습니다.

노트를 열면 3D 렌더러는 해제되고, 3D 탭으로 돌아오면 선택 대상을 다시 불러옵니다. 카메라 각도나 문 개방 상태의 세션 간 복원은 제공하지 않습니다. 로딩이나 그래픽 오류가 나면 **3D 다시 불러오기**를 사용하세요.

3D 프레임에는 노트 본문과 파일 작업 API를 보내지 않습니다. 컨테이너·부품 ID만 검증해 주고받습니다. [출처](../THIRD_PARTY_NOTICES.md)와 [검증 기록](verification/ess-3d.md)을 참고하세요.
