# Dynote v0.15.0 — 구간별 저널 편집과 Bullet Threading

일반 문서에서도 원하는 부분만 저널처럼 기록할 수 있습니다. 편집 화면에서 텍스트를 드래그하고 **구간 편집 → 저널식 편집 (Bullet Threading) → 선택 구간에 적용**을 선택하세요.

- 선택한 문단이 불릿 블록으로 바뀌며 Tab·Shift+Tab·Enter·Shift+Enter 편집과 상위 블록 연결선이 함께 적용됩니다. **일반 편집**으로 돌아가면 작성한 내용과 Markdown 목록은 유지됩니다.
- 한 문서의 여러 구간을 각각 설정할 수 있습니다. 설정은 문서와 함께 저장되며, Live Preview와 읽기 보기에서는 숨겨지고 소스 보기에서는 확인할 수 있습니다. 연결선은 Live Preview에서 표시됩니다.
- 제목 크기에 맞춰 작은 불릿을 정렬하고, 실제 목록 깊이마다 30px 간격을 적용합니다. 기존 4칸·탭 들여쓰기는 원문을 유지하면서 같은 간격으로 표시합니다.
- 활성 연결선은 Logseq Bullet Threading 플러그인의 기본값을 확인해 2px, 불투명도 100%로 맞췄습니다. 사용자 테마에 따른 색상까지 동일하다는 의미는 아닙니다.
- 선택 끝이 다음 목록 줄의 시작과 같을 때 다음 항목까지 포함되던 문제와 잘못 중첩된 구간이 일부 활성화되던 문제를 수정했습니다. 드래그 도중 안내 문구 변화가 본문 위치를 움직이지 않도록 했습니다.
- 기존 일간 저널의 블록 작성, 접기·펼치기, 사용자 템플릿, 노트 저장과 선택한 AI 제공자 흐름을 유지합니다. AI 로그인 없이 일반 문서를 작성할 수 있습니다.

## 설치

Apple Silicon Mac: `Dynote-0.15.0-macos-arm64.dmg`를 열고 Dynote를 Applications 폴더로 옮깁니다. Mac 앱은 기존과 같은 ad-hoc 무결성 서명이며 Apple Developer ID 배포 서명·공증이 없어 macOS에서 차단될 수 있습니다. 공식 출처와 체크섬을 확인한 뒤 앱별 실행 허용 여부를 직접 결정하세요.

Windows x64: `Dynote-0.15.0-windows-x64.zip` 전체를 풀고 `Dynote-win32-x64/Dynote.exe`를 실행합니다. EXE 옆의 resources·DLL도 함께 유지하세요.

교체 전에 기존 앱을 정상 종료하세요. 노트 폴더와 앱 데이터는 유지됩니다. 플랫폼별 SHA256SUMS 파일과 패키지 검증 JSON을 함께 제공합니다. 앱 내 업데이트에서 시험판을 받으려면 베타 포함 설정을 확인하세요.

## 검증 범위

Mac arm64와 Windows x64의 네이티브 CI에서 전체 단위 테스트·보안 검사·패키징·소스 비교를 수행하고, 실제 앱의 드래그 선택·모드 전환·불릿 변환·연결선·저장·재시작과 기존 저널·Git·AI 검토 흐름을 확인한 뒤 공개 베타로 게시합니다. AI 응답은 결정적 테스트 이벤트를 사용하며 실제 계정 로그인·유료 모델 추론, Windows ARM·Intel Mac·Linux 실행은 이 검증에 포함하지 않습니다.

Logseq 웹 동작과 플러그인 기본 설정을 참고해 독립 구현했으며 Logseq 코드나 데이터베이스를 포함하지 않습니다.
