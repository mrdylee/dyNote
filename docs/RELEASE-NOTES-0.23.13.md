# Dynote v0.23.13 · Windows x64

- 탐색기에서 왼쪽 패널의 폴더로 파일을 끌어 놓으면 이동합니다. Ctrl을 누른 채 놓으면 복사합니다. 같은 이름의 파일이 있으면 새 이름을 붙이고, 같은 폴더 안에서 이동하면 원본을 유지합니다.
- 파일을 본문에 놓으면 읽기 전용 미리보기가 열립니다. HTML은 문서 안의 표, 스타일, 이미지와 charset을 지정한 한글 HTML을 지원합니다.
- 설정 → 테마에서 10가지 색상을 선택할 수 있습니다. 문서로 저장하기 전인 녹색 초안 탭은 닫기 전에 한 번 더 확인합니다.
- 파일 전송을 마친 뒤 최종 파일명을 부여합니다. 보관함의 Git 복원 대상 파일은 드래그할 때 파일당 25MB까지 지원합니다.

기존 Dynote를 종료하고 `Dynote-0.23.13-windows-x64-Setup.exe`를 실행하세요. 설치형 v0.23.12에서는 **설정 → 업데이트 → 시험 버전도 확인**을 켜면 앱에서 업데이트할 수 있습니다.
