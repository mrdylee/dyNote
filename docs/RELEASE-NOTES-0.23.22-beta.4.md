# Dynote v0.23.22-beta.4 · Windows x64 시험판

두 PC에서 같은 개인 저널의 같은 줄을 다르게 편집하면, **버전 확인**에서 문서 전체를 나란히 보고 남길 내용을 고를 수 있습니다.

1. 클라우드 PC와 로컬 PC에서 **설정 → 업데이트 → 시험 버전도 확인 → 지금 업데이트 확인**을 선택해 설치하세요.
2. **여러 PC에서 이어 쓰기**를 사용하는 개인 저널에서 충돌이 표시되면 해당 날짜의 **버전 확인**을 여세요.
3. 왼쪽 수정본의 **→** 또는 오른쪽 수정본의 **←**를 눌러 해당 구간을 가운데 **병합 결과**로 가져오세요. 가운데에서 **원문 유지** 또는 **되돌리기**도 선택할 수 있습니다.
4. 구간별 선택을 마치고 **선택한 내용 반영**을 누르면 결과가 저장되고 다음 동기화 때 다른 PC에도 반영됩니다.

두 PC가 동시에 업로드해 원격 브랜치가 먼저 변경된 경우의 재시도 처리도 개선했습니다.
