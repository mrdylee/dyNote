# Dynote v0.23.2 — 파일 이름 변경과 Copilot 프로젝트 표시

- 왼쪽 개인·팀 노트 목록에서 파일이나 폴더를 선택하고 **F2**를 누르거나 우클릭 메뉴를 사용해 이름을 변경할 수 있습니다. 연결된 문서의 링크도 갱신합니다.
- `Copilot Note`와 이전에 가져온 `AI Conversations`의 프로젝트 폴더에 실제 프로젝트 이름을 표시합니다. 저장 경로를 유지해 기존 저널 링크가 열리고, 세션을 재가져와도 기존 기록에 이어집니다.
- 새 보관함에서 Copilot 대화는 `Copilot Note`에 가져오고, 문서 안에서는 `내 프롬프트`와 `Copilot 답변` 제목으로 구분합니다.

## 설치

- Apple Silicon Mac은 DMG 또는 ZIP을 사용합니다. 앱 무결성 서명을 적용합니다. Apple 배포 공증은 없습니다.
- Windows x64는 ZIP 전체를 풀고 `Dynote-win32-x64/Dynote.exe`를 실행합니다.
- 앱의 설정 → 업데이트 → 시험 버전 포함에서도 받을 수 있습니다.
