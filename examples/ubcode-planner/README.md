# ubCode planner example

Three requirements, two designs and three tests for Dynote's capture workflow. `schemas.json` checks that every requirement has a linked test.

Run `ubc check --output-format json` in this folder. For the missing-link and changed-requirement evaluation, run `UBCODE_BINARY=/absolute/path/to/ubc node scripts/verify-ubcode-planner.mjs` from the repository root.

This example contains synthetic text only and is covered by the repository's MIT license. ubCode itself has separate licensing terms and is not bundled. See `docs/verification/ubcode-planner.md` for the observed CLI results and limitations.
